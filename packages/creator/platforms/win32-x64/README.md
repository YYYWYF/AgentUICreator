# Creator Python Agent runtime (win32-x64)

Internal platform distribution for `@za38.03/agent-ui-creator`. Install Creator; it selects this package automatically. Includes pinned standalone CPython, Python dependencies, Agent source, contracts and license resources. No Python installation or pip bootstrap is needed at runtime. The TypeScript host is delivered by the automatically installed Operator package.

See `packages/creator/docs/python-distribution.md` in the source repository for build and release instructions.
