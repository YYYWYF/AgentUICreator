# 自定义样式的 Light / Dark 适配

日期：2026-10-23。范围：Agent 前端的共享展示样式，以及悬浮式、嵌入式示例的项目样式。

## 实现

- 共享输入框、消息、工具、卡片、菜单和 Markdown 样式从 Violet 限定扩展到 Agent UI 的全部主题边界，保留原有结构尺寸、间距和字体。
- Light / Dark 的产品交互颜色由各自 `primary`、`background`、`card`、`foreground`、`border` 等语义变量派生。官方 Light / Dark 调色板快照及 Violet 调色板文件未修改。
- compact 样式保留欢迎区、建议卡片、输入框和悬浮面板的布局。固定颜色集中为配色变量；原有 Violet 数值留在其专属覆盖块中。
- 欢迎装饰图形使用同一 SVG 几何的 CSS mask，图形颜色随主题变量变化；短窗口下仍隐藏该装饰。
- 同步更新现有 assistant / embedded 项目样式及新项目交付模板，未更新项目源码基线、AppUIModel、Runtime 或上游 vendor。

## 验证

以下检查均在 Windows 上实际运行：

- Plugins 类型检查、发布构建、公开声明边界与可选 Lexical 边界通过。
- platform、assistant、embedded 三个独立示例的类型检查及 Vite 生产构建通过。
- 新增跨主题测试验证两类主题根的产品颜色变量均可解析，Light / Dark 不泄漏 Violet 配色，并保留输入框、消息、工具及建议卡片的结构规则。
- 主题合同、Dark variant 与弹层边界、样式隔离、跨主题展示及品牌测试共 19 项：17 项通过，2 项旧测试因对比度辅助函数不支持现有 `#866DFD` HEX 格式而失败。这两项只读取未修改的 Violet 调色板，未为适配改色或降低其阈值。
- 修复同一品牌测试中的 Windows CRLF 快照归一化，并将 Composer 展示钩子的检查指向现有唯一实现 owner。
- 新项目 compact 样式交付与主题配置合同测试 4 项通过，覆盖三种形态和带空格的 Windows 源码路径。
- Plugins 目录、472 个源码快照及可接管实现闭包核对通过；三个示例的生产 CSS 均包含共享主题适配。网站与离线文档重建后校验通过。
