# Creator Agent 600 秒超时归因诊断

日期：2026-10-08（Asia/Shanghai）。基线：`d37a8e2653cf8f5f20e63c5ab80895e19aa1d1cf`。

## 结论

归类 **MIXED，主因素 MODEL_LATENCY**，综合置信程度中等。本次可观测时间的 **99.10% 在模型请求中**，其中包含生成/流式等待与传输失败，工具执行仅占 0.64%。上下文增长和 Creator 多轮只读探索确实存在，但没有对照证据把它们各自造成的延迟从模型等待中剥离，不能分配根因百分比，更不能把网络失败全部归为模型计算慢。

原始 8192 轮是 `TimeoutError`；唯一一次诊断复跑用时 **600.005 秒**，实际终态是 **ModelTransportError**（第 14 逻辑轮三次传输尝试耗尽）。不是成功验收，也不能将复跑错误类型改写为 TimeoutError。原始轮已形成计划但未生成插件；本次连计划也未形成，源码改动均为零。

- 进程覆盖 `CREATOR_MODEL_MAX_TOKENS=8192`；单请求配置 120 秒，整轮 `asyncio.wait_for` 600 秒；原有 24 个逻辑模型调用上限、2 次重试均保留。
- 在独立基线工作树运行，复用原 B Fixture，源码哈希无漂移，Host 控制产物在基线重新编译；复用现有外部依赖链接，非全新依赖安装。
- 原始开发请求、系统 Prompt、开发 Skill、工具 Schema/返回格式、组件选择规则及生产实现未改。
- 只添加测试回调/日志派生统计，`finally` 首先保存 `creator.protocol.metrics.to_dict()`、生命周期与结果大小，再做源码审计。未保存模型请求正文、密钥、Authorization；发布 JSON 不含工具正文。

## 执行路径与复杂参数

诊断轮 33 次提出工具调用、33 次执行，16 次 read_file、6 次 glob、5 次 grep，13 轮成功均返回工具调用。第 6–8 轮连续文件发现/搜索、第 9–13 轮继续读取 locale 与现有插件；没有 mutation、开发计划或交付验证。它有“只读探索轮次多、业务成果不足”的效率证据，但不是多次重复同一成功结果的确定死循环。协议计数 repeatedToolLoops=0 也不能否定更广义的低效率探索。

诊断轮 finish_reason=length 为 0，输出最高 3,794 Token，未达到 8,192；无无效工具参数、ModelToolProtocolError、ModelResponseTruncatedError，协议修复 0。**本次没有调用 prepare_ui_plugin_development**，所以不能判断该工具复杂参数是否拖慢本次运行。原始轮确实成功执行过它，attempt-1 有 ModelToolProtocolError，但旧日志不足以证明同一复杂调用被反复修复。

复杂参数生成与工具结果过大分开判断：当前没有复杂参数截断证据；最大实际返回来自 Skill 读取，不是开发计划工具。

## 归因与最小建议（不实施）

| 类别 | 支持程度与边界 |
| --- | --- |
| MODEL_LATENCY | 强：99.10% 时间落在请求等待，13 次成功平均 30.59 秒，还有流式停顿及连接失败；只能确定模型/传输路径，不能孤立证明服务商计算延迟 |
| CONTEXT_GROWTH | 增长证据强，因果证据有限：消息 3.38 倍、输入 Token 2.55 倍；耗时相关受输出长度混杂 |
| TOOL_SCHEMA_OVERHEAD | 固定成本明确；首轮约 30.36% 近似输入，是否过多/可省及其秒数未证实 |
| TOOL_RESULT_BLOAT | 历史累积明确；巨大返回反复复制的证据弱，无近 48k 返回，同参数同结果重复为 0 |
| AGENT_LOOP | 低进展探索证据中等：原始 18+ 轮无源码、本次 13 轮无计划无源码；存在拒绝、失败读取，但非确定重复规划死循环 |
| MIXED | 综合分类：模型/传输等待为主，上下文与多轮探索为可观测放大因素，其独立耗时无法分摊 |

最小建议仅供后续评估：同一 Host 检查串行执行以减少 busy 后再次请求模型；原始轮读取证据未变时避免重复 locale 阅读；评估现有上下文的按需读取和现有阶段工具集的边界。不要据此直接改变 Prompt、Skill、Schema、超时或启用摘要。流式停顿/连接失败按模型/传输问题记录，本次暂不修复。没有出现需要再运行 600 秒才能解释的相互矛盾证据；错误类型差异已如实记录。
