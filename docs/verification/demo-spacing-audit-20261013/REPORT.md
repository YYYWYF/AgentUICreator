# Demo spacing audit · 2026-10-13

目标：实际 http://127.0.0.1:5176/，通过 5174 Creator 的“示例与回放”逐个点击全部33个预置Demo，另检查2份本地回放。仅为本次捕获状态的间距验收，不代表所有交互、主题、尺寸、平台均通过。

结论：预置Demo中28项捕获状态未见明显间距异常；3项有具体间距问题；2项刷新后回到欢迎页，恢复后的间距无法验收。图表和两份本地回放未见原先的大空档。

环境：macOS，实际IAB预览1280×720，默认紫色主题。普通Demo用0.1×；取消和刷新恢复用1×。开发服务因项目控制接口过期重新启动，仍运行。缺失的表单Demo资源通过“下载资源”安装；安装后侧栏表单持续显示，造成后续会话宽度缩小。未提交资料表单、未下载虚拟PDF。没有改动产品代码来掩盖审查结果。

## 具体观察与限制

- **发送文字、图片与文件**：固定文本输出间距正常；未上传图片/PDF，本次不宣称附件协议完整验收。
- **携带上下文向 Agent 提问**：当前输入未提供人员上下文，返回“没有找到当前可用的人员上下文”；该提示排版正常。
- **思考 → 工具时间线 → 回答**：需调整：原始工具详情展开后三张工具卡片边框紧贴；外层思考→时间线→回答的节点间距实测16px。
- **思考占位**：当前项目仍显示详细思考组件；本次只验收实际展示间距，未将“仅占位”配置能力判通过。
- **前端工具填写表单**：通过UI安装缺失资源后运行完成，表单已填写但未提交；安装后右侧表单在其他Demo也持续显示。
- **工具搜索网页并返回结果**：需调整：完成态结果列表仍有 min-height:5.75rem；两条来源之后留出多余空白。
- **工具返回检索片段**：需调整：完成态列表仍有 min-height:7rem（112px）；单条片段卡片未占满，操作栏前多出约34px空白。
- **向用户提问并继续回答**：提问卡片和选择后摘要间距正常；选择后本次未看到后续回答，未判续答功能通过。
- **A2UI 交互表单**：表单控件间距无明显叠加空白；截图包含顶部与下部，Save动作可返回续答。
- **A2UI 订单确认卡片**：订单卡片间距无明显叠加空白；Cancel测试可续答，但内容重复属于另一个展示问题。
- **子智能体运行错误**：折叠和展开间距正常；错误任务外部标题仍显示“已完成”，状态语义另列观察。
- **多个会话同时运行**：记录了两次请求和最终A输出；此次只判输出排版，未宣称并发隔离完整验收。
- **刷新后继续接收长任务回复**：未通过恢复验证：刷新前正常显示首段；刷新后回到欢迎页，未恢复该会话，无法验收恢复后的间距。
