# Creator 新能力开发确认流程：实现与复测

已实现：检查相关公开 API / 项目源码后即可提出缺失能力方案；无需证明全仓不存在同类实现。通过真实 Host 的“开始开发 / 调整需求 / 暂不处理”取得范围授权，再沿用已有编辑、Service、组合及验证工具执行。保留通用 Agent 的工具选择能力。

涉及的必需 Service 可以在同一方案中列明提供方、使用方及路径，经同一次确认取得分别可验证的授权。项目自有插件无需 npm 源码接管；vendor、Runtime 修改、源码接管及依赖安装均未包含在该授权内。

当前真实授权与检查过的源码归属会保留在模型输入中；重复源码、导航变化不再冒充新证据。没有增加累计模型调用或图步骤上限。

## 验证

- Creator：49 个测试文件、485 项测试通过。包含真实 LangGraph interrupt/resume 与既有写入工具集成测试。
- Creator 类型检查、国际化检查、Creator 构建及打包文档验证通过。Operator contract inventory 已对齐。
- 浏览器受控测试：显示完整方案及三个选项，暂缓后零文件变更；真实模型的阶段测试也通过原生 UI 模拟确认，确认前源码哈希未变化。
- 所有写入测试均在一次性测试项目进行。模拟点击只用于这些 QA 项目，不代表用户批准其他工程、vendor 或源码接管。
- 未修改 vendor、Runtime 或维护中的示例 Host。已有其他工作区改动未纳入本次修复。
- 实际环境为 macOS；已审查新增逻辑的路径与进程边界，未进行真实 Windows 验收。

## 相同模型、原始任务的实际记录

模型：deepseek-v4.1-flash；上下文预算 65536，输出预算 8192，temperature=0.2，单请求 timeout=120 秒。

原始需求：给帮助卡片的 headerActions 添加“知道了”按钮，点击隐藏正文，标题重新展开，切换主题后正常。

| 测试 | 秒 | 工具调用 | 已报告 token 累计下界 | 修改文件 | 结果 |
| --- | ---: | ---: | ---: | ---: | --- |
| 自然执行（早期修复版本） | 1200.242 | 64 | 1,027,077 | 0 | QA 截止时间停止，未交付完整功能 |
| 批准后执行（权限措辞修复前） | 600.215 | 69 | 1,088,262 | 0 | QA 截止时间停止，未交付完整功能 |
| 批准后执行（最终版本） | 600.265 | 84 | 1,410,174 | 1 | QA 截止时间停止，未交付完整功能 |

第一轮是自然执行的早期修复版本。后两轮仅隔离测试“批准后的执行”：用两次脚本模型响应重放真实模型上一轮给出的同一方案及源码读取，再通过原生 UI 在测试工程模拟确认，其后交给真实 DeepSeek。脚本响应没有真实模型 token；表中工具数包含这段准备及中断重放。因此这些阶段测试不能充当自然端到端提速证明。

最终版本首次成功写入发生于第 31 次工具调用、测试开始后 159.346 秒；新增 src/agent-ui/hooks/useQuickHelpCardExpanded.tsx。真实请求中已观测到当前方案 authorized，以及 quick-help-card 为项目自有实现、无需接管。此前两轮均为零写入。

但最终阶段测试仍未通过：600.265 秒内只写入了控制模块，按钮、父卡片、插槽组合和交互验证未完成。零写入已突破，不能据此声称复杂任务已解决。后续仍有大量查询；摘要中还出现把“已知需修改的已有文件”当作整个授权范围的错误表述，需要继续单独验证和处理。

20 分钟 / 10 分钟是 QA 的观察窗口，到了窗口后调用普通停止操作；不是产品累计调用限制，也不是证明模型自然结束或崩溃。

token 取自已完成的 Agent 和压缩模型日志 usage，包含模型报告的缓存输入及 reasoning。未返回 usage 的请求不在累计内，所以记为下界；不是单次上下文长度，也不直接等于计费 token。流关闭后的 HTTP AbortError 未一概判为模型服务故障。

## 证据入口

- results.json：汇总、token 分类、模型请求数和各次压缩前后估算。
- results.csv：简表。
- final-checks.log、final-build.log：最终检查。
- ui-final/ui-defer/proposal-top.png：原生方案卡片。
- candidate/：自然执行日志。
- execution/approved-execution/：较早权限措辞版本的执行阶段日志。
- execution-ownership/approved-execution/：最终版本的执行阶段日志、测试工程和单个写入文件。
- execution-ownership/model-http-requests.json：脱敏请求遥测，以及实际送达模型的 Host 授权/归属状态。

完整任务尚未有目标工程 typecheck/build 和按钮点击、键盘、主题切换的通过证据。
