# 功能概览

Agent UI 把对话、任务过程和结果放在同一个界面中。用户既可以直接向助理提问，也可以结合当前业务页面和手边的材料，完成分析、查阅与处理工作。

界面由插件组合而成。消息输入框、会话列表、任务进度卡片和图表展示等都是插件，可以按需搭配。

需要后端数据的插件，在“显示条件与数据来源”中说明事件格式、必需字段和显示条件，汇总见[插件显示条件与 AG-UI 数据](/plugins/ag-ui-data.md)。各插件的“属性”列出组件定制接口。

## 界面形态

同一套对话能力可以放进不同的界面形态，适应不同的使用场景。

**工作台**：以聊天为中心，把会话列表、消息和输入框集中在一个工作区。

![工作台：会话列表、开场建议和消息输入框](/images/agent-ui/layout-workbench-hd.png)

**悬浮助手**：从业务页面角落展开，用户可以一边查看页面，一边与助理沟通。

![悬浮助手：在业务页面上展开聊天窗口](/images/agent-ui/layout-assistant-hd.png)

**嵌入式助手**：与文档、表单等内容并排，融入页面中的固定区域。

![嵌入式助手：左侧编辑文档，右侧与 Agent 对话](/images/agent-ui/layout-embedded-hd.png)

## 业务对话

接入业务后，助理可以结合当前工单、订单或文档回答问题，也可以根据对话打开相关内容。用户不必反复复制页面信息，就能围绕同一件事继续沟通。

![从工单页面发起分析，右侧助理结合当前工单给出补寄建议](/images/agent-ui/outcome-business-analysis.png)

除了文字提问，还可以带上附件、引用已有消息，或使用语音与快捷输入。回复逐步呈现，支持文字、表格和代码；需要补充条件时，也能停止、修改问题或重新获取回答。

![发送季度销售数据附件后，获得销售表现总结和后续建议](/images/agent-ui/outcome-material-review.jpg)

## 任务协作

处理复杂任务时，界面可以呈现思考内容、工具调用、计划和进度，让用户了解当前做到哪一步。需要补充信息或确认操作时，助理可以在对话中提问、提供选项，或等待用户审批后继续。

![任务计划：已完成的步骤、当前步骤和停止按钮](/images/agent-ui/execution-plan.jpg)

![操作确认：展示具体操作，并提供允许和拒绝按钮](/images/plugins/tool-fallback-approval.jpg)

## 结果交付

一次回复可以同时包含分析结论、图表、参考来源和报告文件。用户既能查看结果和依据，也能复制、导出或下载，继续编辑与分享。

![销售复盘成品：分析结论、季度图表、数据来源和可下载报告](/images/agent-ui/outcome-report-delivery.png)

## 应用体验

通过会话列表查找历史记录，继续之前的问题，或开始新的对话。主题、界面语言、助理名称与头像，以及登录和账号入口，让对话界面与应用的整体体验保持一致。

各项功能的效果与使用说明，见左侧对应的插件页面。
