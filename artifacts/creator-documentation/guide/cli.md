# Creator CLI 参数

安装的命令为 `agent-ui-creator`。它属于开发工具，默认只启动本地 Creator 服务。图形界面必须通过已接入 Dock 的宿主工程页面使用，**宿主开发服务器需另外启动**。

| 参数                   | 短名   | 行为                                                    |
| -------------------- | ---- | ----------------------------------------------------- |
| `--project <目录>`     | `-p` | 可选预选目标项目；路径按当前启动目录解析。省略时首次由用户选择，后续尝试恢复记住的工程。          |
| `--config-root <目录>` | `-c` | 工具配置根目录，其下读取 `.agent-ui/creator/.env.local`；默认当前工作目录。 |
| `--message <需求>`     | `-m` | 终端执行单次需求；未传 project 时以当前目录为目标，结束后断开工具连接。              |
| `--port <数字>`        | 无    | 工具端口，0–65535 整数；显式端口占用时报错。                            |
| `--help`             | `-h` | 输出帮助，不启动服务。                                           |

```sh
agent-ui-creator --port 47833
agent-ui-creator --project "C:\work\my-app" --config-root "C:\work\tools" --message "说明当前界面组成，暂不修改文件"
```

## 默认值与退出行为

端口优先使用 `--port`，其次进程 `CREATOR_PORT`。未显式设置时常规默认 47832，可在占用时选择可用端口；**以实际终端 URL 为准**。端口 0 会由系统分配空闲端口；配置了固定 Creator 地址的页面不应使用它。

Creator 不自动打开浏览器，也不提供独立启动页。直接访问工具根地址或单独打开 `dock.html` 会被拒绝。

按 Ctrl+C 正常停止并等待清理。CLI 错误设置失败退出状态。

## 注意事项

目录选择器从启动目录开始，不受 `--config-root` 影响。工程选择见[开始使用](/start/index.md#选择工程)。

可选的 `--project` **只预选，不自动初始化**。终端执行同样需要遵守项目权限和变更确认要求。需要多轮回答问题时，建议使用图形界面。不要将模型密钥写进命令行参数或 shell 历史。
