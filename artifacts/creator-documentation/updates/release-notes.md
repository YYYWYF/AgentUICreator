# 插件更新

## 发布前功能草稿

以下汇总当前能力，不代表已发布版本的变更记录。正式版本和兼容信息以实际包元数据及更新中心读取的官方发行记录为准。

提供可按需启用、组合和定制的官方插件，覆盖从消息输入到结果交付的常用 Agent 界面功能。

| 功能       | 功能内容                                                 |
| -------- | ---------------------------------------------------- |
| 对话与会话管理  | 会话界面、会话列表、新建会话、开场建议、历史对话加载和临时通知。                     |
| 消息输入与编辑  | 消息输入、发送与停止、附件添加、消息引用、消息编辑、语音输入、`@` 提及、`/` 快捷命令及输入标签。 |
| 消息与回复操作  | 流式文本、Markdown、代码块，回复复制、重新生成、Markdown 导出和评价。          |
| 思考与工具    | 思考内容、处理中提示、工具分组、调用详情、执行时间线和 SubAgent 任务展示。           |
| 人机交互     | 操作审批、允许或拒绝操作，以及回答 Agent 提问后继续执行。                     |
| 状态与任务进度  | Agent 工作状态、任务计划、步骤完成状态和后台任务进度。                       |
| 结果与来源    | 生成文件、图表、引用来源、上下文检索、文档片段和网页搜索结果。                      |
| 外观、语言与账号 | Agent 名称与头像、浅色/深色/紫色主题、中英文切换、登录入口、账号信息和退出登录。         |

附件、语音、评价、认证和历史记录等能力需要相应业务服务支持；Lexical 输入和动态界面等扩展按需配置。页面效果、插件选用与配置见[功能与插件](/plugins/index.md)。

## 如何更新插件

在 Creator 顶部齿轮 →「插件更新」中刷新版本信息，选择目标版本、查看变更并准备升级。确认具体方案后，工具安装依赖并运行工程检查。目前自动安装支持已有锁文件的独立 npm/pnpm 项目。

更新页会列出待升级包的当前版本、目标版本和累计变更，也可以展开查看逐版本记录：

![更新中心展示包版本、累计变更和逐版本记录](/images/updates/package-changes.png)

点击「准备升级」后，先核对升级范围，再确认安装：

![升级确认方案展示待升级包、版本及源码保留说明](/images/updates/package-plan.png)

> 截图中的版本号和变更内容为演示数据，不代表实际发布记录。

### 已接管源码的插件

依赖升级后，本地实现仍保留原有定制，需要另外确认源码同步：

1. 在同一更新页的「源码更新」中，选择插件并点击「查看同步方案」。
2. 审查改动，按提示确认更新、自行合并或让 Creator 合并。
3. 运行相关检查并确认页面效果，再点击「验证并完成同步」。

同步只处理已接管的实现，保留项目的组件参数、组合、布局和连接配置。首次接管见[源码接管](/development/source-takeover.md)。
