# 官方插件源码接管

大多数颜色、文案和排版调整可以直接让 Creator 完成。如果它提出“接管源码”，表示要把该插件的实现放入项目，由项目自行修改和维护。

## 接管前评估

让 Creator 说明具体插件、当前版本、要增加或修改的文件、为什么普通配置不能满足需求，以及如何保留现有定制。看清这次范围后，再决定是否同意。

> 先检查现有组件参数能否实现。如果确实需要接管，请列出具体插件、文件改动和后续更新方式，等我确认。

## 接管后的维护

可以继续让 Creator 修改该插件。更新 npm 依赖时，本地实现不会自动变成新版；需要采用官方新版改动时，另外执行[源码同步](/updates/release-notes.md#已接管源码的插件)。

修改完成后，按[定制效果验证](/guide/examples/verify-results.md#检查清单)确认原功能和定制仍然可用。
