# 消息与标签编辑（lexical-edit-composer）

<figure className="plugin-preview">

![消息编辑界面](/images/plugins/lexical-edit-composer.png)

<figcaption>已有用户消息正在编辑；保存与取消作用于这条消息，不替换底部的新消息草稿。</figcaption>
</figure>

编辑已有用户消息中的文字和引用标签，并沿用消息编辑原有的保存、取消与重新提交流程。它服务于当前被编辑的消息，和底部准备下一条问题的 Composer 具有不同的草稿作用域。

## 修改已有消息并重新提交

<figure className="plugin-preview">

![用户消息旁的铅笔编辑入口](/images/plugins/lexical-edit-composer-entry.png)

<figcaption>在已有用户消息旁找到铅笔图标，点击“编辑”进入页首所示的消息编辑区。</figcaption>
</figure>

消息进入编辑状态后，原文字与支持的引用标签显示在编辑区。保存后通过现有消息编辑流程重新提交；取消则保留原消息。中文输入法保护、引用的整体选择与删除由现有输入实现处理。

没有自定义 `input` 时使用 Lexical。消息含当前编辑器不支持的指令时，保留普通输入回退，让已有消息仍能继续修改，不强行丢弃未知文字。

## 与 Composer 联动

编辑使用该消息的选择快照；仍在正文中的引用继续关联原始业务选择，移除引用后不再携带对应数据。重发请求还会经过同一个最终 [Composer `requestAdapter`](./composer#请求适配)。

插件不因为打开编辑区而新增一份 `pluginData[lexical-edit-composer]`。有历史元数据时沿用消息的原始选择；只存了引用标记的历史不能恢复标记之外的业务 `data`，见 [Composer 的历史与快照](./composer#提交后的快照重发与会话切换)。

编辑区不应拿底部新消息的业务选择来补充旧消息。业务卡片的 `useComposer()` 操作要放在它实际要影响的输入作用域中；不要用底部输入控制器代替已有消息编辑的保存与取消。

## 定制标签与输入外观

标签身份和格式化规则与[主输入框](./lexical-composer-input#conversationcomposerdirectivechipprops)一致。在项目已有编辑入口通过 `inputProps.directiveChip` 改展示，通过 `inputProps.className/style` 改输入样式；替换整个 `input` 时要保留已有消息编辑上下文和提交、取消入口。

`inputProps.directivePluginProps.onDirectiveSelect` 是观察回调，不自动产生业务数据。自定义 `formatter` 时仍需成对提供可往返的序列化与解析，确保取消后保留原消息、保存后引用 ID 和文字顺序一致。

## 快捷键与自动聚焦 {#快捷键与自动聚焦}

<span id="example-1"></span>

Lexical 为可选输入实现，通过 /lexical 入口导入；沿用项目已有编辑与输入组合。

```tsx
import type { ComponentProps } from 'react';
import { CanonicalConversationLexicalEditComposer } from '@za38.03/agent-ui-plugins/lexical';

export function Example(props: ComponentProps<typeof CanonicalConversationLexicalEditComposer>) {
  return <CanonicalConversationLexicalEditComposer {...props}
    inputProps={{ ...props.inputProps, submitMode: "ctrlEnter", autoFocus: false }} />;
}
```

## Escape 不取消编辑 {#escape-不取消编辑}

关闭 Escape 取消后，用户继续通过已有取消按钮退出编辑。

```tsx
import type { ComponentProps } from 'react';
import { CanonicalConversationLexicalEditComposer } from '@za38.03/agent-ui-plugins/lexical';

export function Example(props: ComponentProps<typeof CanonicalConversationLexicalEditComposer>) {
  return <CanonicalConversationLexicalEditComposer {...props}
    inputProps={{ ...props.inputProps, cancelOnEscape: false }} />;
}
```

## API

<span id="属性"></span>
<span id="开发-api"></span>

入口来自 `@za38.03/agent-ui-plugins/lexical`：`CanonicalConversationLexicalEditComposer`。样式通过 `inputProps` 配置，自定义输入内容通过 `input` 提供。

| 属性 | 类型 | 省略时 / 用途 |
| --- | --- | --- |
| `input?` | `ReactNode` | 替换消息编辑输入 |
| `inputProps?` | `ConversationLexicalInputProps` | Lexical 输入属性，详见下表 |

没有自定义 `input` 时，默认使用 Lexical；草稿含不支持的指令时保留现有普通输入回退。保存修改和取消编辑仍由现有消息编辑组件处理。

### inputProps

下表是编辑输入组件的嵌套属性；输入元素还继承 `div` 原生属性。

| 属性 | 类型 | 省略时 / 用途 |
| --- | --- | --- |
| `inputProps.submitMode?` | `'enter' \| 'ctrlEnter' \| 'none'` | 默认 `enter`；由已安装 Lexical 输入组件处理 |
| `inputProps.cancelOnEscape?` | `boolean` | 默认 `true`，Esc 取消编辑策略 |
| `inputProps.placeholder?` | `string` | 默认使用所在输入区的提示文字 |
| `inputProps.autoFocus?` | `boolean` | 默认使用所在输入区的自动聚焦设置 |
| `inputProps.directivePluginProps?` | [`{ onDirectiveSelect?: (item: ConversationLexicalTriggerItem) => void }`](./lexical-composer-input#conversationlexicaltriggeritem) | 指令选中回调 |
| `inputProps.directiveChip?` | [`FC<ConversationComposerDirectiveChipProps>`](./lexical-composer-input#conversationcomposerdirectivechipprops) | 默认 `ConversationComposerDirectiveChip`，替换指令标签组件 |
| `inputProps.formatter?` | [`{ serialize(item: ConversationLexicalTriggerItem): string; parse(text: string): readonly ConversationLexicalSegment[] }`](./lexical-composer-input#conversationlexicaltriggeritem) | 默认项目统一指令格式化器；返回片段见 [`ConversationLexicalSegment`](./lexical-composer-input#conversationlexicalsegment) |
| `inputProps.children?` | `ReactNode` | 追加 Lexical 子插件；现有中文输入法保护仍保留 |

这个输入组件需要放在项目现有的消息输入区或消息编辑区内，才能读取草稿、提示文字和聚焦设置。它只替换输入界面，继续使用原有会话。

`inputProps` 还支持输入元素的 `className`、`style`、`id`、`role`、`aria-*`、`data-*` 与原生事件回调；它们属于嵌套输入属性，不是本插件的根属性。

### 编辑已有消息中的引用

这里的标签、候选和序列化行为与[主输入框的引用定制](./lexical-composer-input#conversationcomposerdirectivechipprops)相同。编辑区通过 `inputProps.directiveChip` 传入标签组件，通过 `inputProps.directivePluginProps.onDirectiveSelect` 观察选中，通过 `inputProps.formatter` 提供成对的序列化／解析方法。

修改后应检查已有消息进入编辑、取消后保留原消息、重新提交后引用身份仍正确。普通样式修改只设置 `inputProps.className` / `style`，无需重写格式化器。
