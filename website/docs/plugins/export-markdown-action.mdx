# 导出回复（export-markdown-action）

在更多操作中导出完整 assistant 响应的 Markdown。

## 界面与功能

在回复的更多菜单中选择导出，浏览器下载该次回复的 Markdown 文件。

## 如何启用和使用

在已创建的工程中启用此 Plugin，放到当前组合支持的位置。可以请 Creator 按下方示例调整；先保留已有页面和其他功能，再检查预览效果。

当前官方预设：在工作台、悬浮式、嵌入式中启用。已有项目可能已经定制，以实际页面为准。

可以把下面的需求发给 Creator：

> 在当前工程中配置「导出回复」，保留已有布局和其他功能。先检查所需服务是否可用，完成后说明改了哪里、怎样验证。

## 使用前提

浏览器需允许下载。导出范围是当前完整回复，包含多段 assistant 内容，不导出整个会话。

## 属性

优先在项目已有 Plugin 应用文件中设置参数；不需要为了改外观复制官方实现。

| 参数 | 用途 |
| --- | --- |
| `menuLabel` | 导出菜单项文字。 |
| `buttonProps` | 按钮外观与原生事件。 |
| `menuItemProps` | 菜单项外观与事件。 |

下面是复用公开组件的应用层写法，放在现有组件上下文中使用。`props` 来自该组件公开类型，文案由项目语言配置传入：

```tsx
import type { ComponentProps } from "react";
import { ConversationCanonicalResponseExportMarkdownAction } from "@za38.03/agent-ui-plugins";

type Props = ComponentProps<typeof ConversationCanonicalResponseExportMarkdownAction>;
export function ProjectView(props: Props) {
  return <ConversationCanonicalResponseExportMarkdownAction {...props} />;
}
```

## 验证结果

在当前项目检查正常、不可用、失败和取消中与此功能相关的状态。涉及附件、语音、登录、历史和恢复时，分别测试实际业务服务；使用 Mock 时注明它是演示数据。

如果只通过类型检查或构建，仍需在页面验证。失败时查看具体提示，不直接清空工程或覆盖已有定制。
