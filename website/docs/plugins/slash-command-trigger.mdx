# 输入 / 使用命令（slash-command-trigger）

在输入中提供应用斜杠命令菜单与选择。

## 界面与功能

输入 / 后出现应用命令菜单，可以搜索、用键盘选择或取消。

## 如何启用和使用

在已创建的工程中启用此 Plugin，放到当前组合支持的位置。可以请 Creator 按下方示例调整；先保留已有页面和其他功能，再检查预览效果。

当前官方预设：未默认加入三种形态，需要按项目需求启用。已有项目可能已经定制，以实际页面为准。

可以把下面的需求发给 Creator：

> 在当前工程中配置「输入 / 使用命令」，保留已有布局和其他功能。先检查所需服务是否可用，完成后说明改了哪里、怎样验证。

## 使用前提

需要应用自己的命令来源。过期、停用的命令不应继续执行。
