# 显示登录门禁（auth-gate）

以共享门禁和认证会话控制需要认证的应用显示。

## 界面与功能

检查登录时显示等待，未登录时显示登录入口，认证完成后进入允许的对话内容。

## 如何启用和使用

先接好业务登录服务，再决定未登录用户看到什么。测试检查中、未登录、登录失败和已登录，不以隐藏界面代替服务端权限校验。

当前官方预设：未默认加入三种形态，需要按项目需求启用。已有项目可能已经定制，以实际页面为准。

可以把下面的需求发给 Creator：

> 在当前工程中配置「显示登录门禁」，保留已有布局和其他功能。先检查所需服务是否可用，完成后说明改了哪里、怎样验证。

## 使用前提

需要真实业务认证；客户端门禁不能保护服务端数据。未登录、无权限和网络失败要分别给出提示。

## 验证结果

在当前项目检查正常、不可用、失败和取消中与此功能相关的状态。涉及附件、语音、登录、历史和恢复时，分别测试实际业务服务；使用 Mock 时注明它是演示数据。

如果只通过类型检查或构建，仍需在页面验证。失败时查看具体提示，不直接清空工程或覆盖已有定制。
