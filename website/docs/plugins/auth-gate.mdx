# 登录认证（开发中）

## 功能与效果

按现有认证状态显示等待、登录表单或开放聊天，业务认证仍由项目服务处理。

### 登录门禁

需要真实业务认证；**客户端门禁不能保护服务端数据**。未登录、无权限和网络失败要分别给出提示。

## 数据来源与显示条件

### 登录状态怎样影响界面 {#authsessionsnapshot}

`state` 由现有认证服务提供，字段及展示行为如下：

| 字段 | 类型 | 组件怎样使用 |
| --- | --- | --- |
| `status` | `'checking' \| 'anonymous' \| 'authenticated'` | 检查中显示等待；未登录显示表单；认证成功后由已有门禁开放聊天 |
| `user` | `AuthUser \| null` | 未登录为 `null`；已登录资料由业务认证结果转换 |
| `busy` | `boolean` | 登录或退出处理中，用来防止重复提交 |
| `error` | `'sign-in-failed' \| 'sign-out-failed' \| null` | 错误码经统一 `locales.auth` 显示为对应提示；不是直接给用户看的文字 |

<span id="authuser"></span>

`AuthUser` 必需 `userId: string` 和 `userName: string`，可选 `avatar: string`。例如业务响应 `{ id: 'u-1', name: '小李' }` 应由适配器转换为 `{ userId: 'u-1', userName: '小李' }`；访问权限继续由实际业务服务验证。

`state` 省略时使用检查中的空快照，不会自动请求业务登录接口。创建及复用服务的方法见[认证服务](#服务)。

<span id="hook"></span>

项目生成的 `useAuthSession` 从 `services/hooks/useAuthSession` 导入。无 selector 返回即时读取与登录／退出句柄，不自动订阅数据；`useAuthSession(selector)` 按需订阅下表的快照字段。`getSnapshot()` 在调用时读取完整快照：

- `getSnapshot()` / `subscribe(listener)`：即时读取或显式订阅认证状态。
- `useAuthSession(selector)`：按需订阅 `status`、`user`、`busy` 或 `error`。
- `session`：可选的 `signIn` / `signOut` 操作对象。
- `serviceAvailable`：服务可用性。

这个 Hook 是项目文件，不是 npm 同名导出。

### 退出登录 {#在业务菜单中退出登录}

例如，业务菜单需要复用当前登录服务退出。调用方在定义中声明 `inject: ['auth.session']`，保留其他依赖；以下组件放在 `plugins/<调用方>/index.tsx`：

```tsx fold height=180
import { useAuthSession } from '../../services/hooks/useAuthSession';

export function SignOutAction({ label, onError }: {
  label: string;
  onError: (error: unknown) => void;
}) {
  const { session } = useAuthSession();
  const snapshot = useAuthSession(state => state);
  return <button type="button"
    disabled={!session || snapshot.busy || snapshot.status !== 'authenticated'}
    onClick={async () => {
      try { await session?.signOut(); }
      catch (error: unknown) { onError(error); }
    }}>{label}</button>;
}
```

`label` 来自项目文案，失败交给 `onError` 显示。退出成功后，同一服务更新账号区和登录门禁；其他插件不必自行清空用户或再次调用 `restore()`。相对路径指向生成项目已有 Hook，移动组件时同步调整。

### API

登录与忙碌按钮文案在 `locales.auth.signIn` / `working` 中设置；按钮属性不接受 `children`。账号与密码的值由表单管理。



在 `CanonicalAuthGatePlugin` 上设置以下属性。

继承 `div` 原生属性，排除 `children` 和原生 `title`。

| 属性 | 类型 | 省略时 / 用途 |
| --- | --- | --- |
| `title?` | `ReactNode` | 默认 `auth.title` |
| `formProps?` | `Omit<ComponentProps<'form'>, 'children'>` | 表单属性；`onSubmit` 中 `preventDefault()` 可阻止默认登录 |
| `accountInputProps?` | `Omit<ComponentProps<typeof Input>, 'children' \| 'value' \| 'defaultValue'>` | 账号输入框原生属性；保留内部输入状态更新 |
| `passwordInputProps?` | `Omit<ComponentProps<typeof Input>, 'children' \| 'value' \| 'defaultValue'>` | 密码输入框原生属性；保留内部输入状态更新 |
| `submitButtonProps?` | `Omit<ComponentProps<typeof Button>, 'children'>` | 登录按钮配置 |
| `session?` | `{ signIn(input: { account: string; password: string }): Promise<void> }` | 现有登录服务 |
| `state?` | [`AuthSessionSnapshot`](#authsessionsnapshot) | 现有认证状态，单独使用组件时默认检查中 |

省略 `state` 时为 `{ status: 'checking', user: null, busy: false, error: null }`，显示检查提示。这些服务类型沿用项目已有 `services/` 声明；不是新增登录状态源。

#### 服务方法 {#服务}

提供 `auth.session: AuthSessionService` 和 `auth.gate`。会话服务的成员为：

| 成员 | 用途或签名 |
| --- | --- |
| `getSnapshot(): AuthSessionSnapshot` | 读取当前认证状态、用户、忙碌状态与错误码。 |
| `subscribe(listener: () => void): () => void` | 订阅变化，返回取消订阅函数；界面优先使用前面的 Hook。 |
| `signIn({ account, password }): Promise<void>` | 登录。 |
| `signOut(): Promise<void>` | 退出。 |
| `restore(): Promise<void>` | 恢复会话。 |
| `gate` | 应用启动状态服务。 |
| `dispose()` | 释放会话服务。 |

首次装配时，从 `@za38.03/agent-ui-plugins/auth-gate` 导入 `createAuthSession(adapter: AuthAdapter)`，返回上述服务。生成项目已负责 `restore()` 和 `dispose()` 生命周期；业务认证请求由项目适配器完成：

| 适配器方法 | 参数与返回值 | 接入什么 |
| --- | --- | --- |
| `restore()` | `Promise<AuthUser \| null>` | 读取已有业务登录态；没有登录时返回 `null` |
| `signIn({ account, password })` | 两个字段均为 `string`，返回 `Promise<AuthUser>` | 委托业务登录方法，成功后转换为 `{ userId, userName, avatar? }` |
| `signOut()` | `Promise<void>` | 委托业务退出方法，失败时拒绝 Promise |
| `subscribe?(listener)` | `listener(user: AuthUser \| null)`，返回取消订阅函数 | 业务登录过期时通知 `null`，资料更新时通知新用户 |

`AuthSessionSnapshot` 和 `AuthUser` 的字段见前文[登录状态与用户资料](#authsessionsnapshot)。门禁服务 `auth.gate` 的 `getSnapshot()` 返回 `status: 'checking' | 'ready' | 'blocked' | 'error'` 和可选 `message`，通过 `subscribe(listener)` 订阅，用于让已有应用随认证状态开放或收起聊天内容。

其他插件复用现有会话，不调用 `restore` 或创建第二份服务。
