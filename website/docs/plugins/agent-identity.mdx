# 显示 Agent 名称与头像（agent-identity）

展示 Agent 的名称、说明和头像等身份信息。

## 界面与功能

欢迎区或侧栏显示项目设置的 Agent 名称、介绍与头像，缺头像时有替代显示。

## 如何启用和使用

在当前项目的 Agent 身份设置中填写名称、说明和头像，检查欢迎区或侧栏实际显示。它不改变服务地址或业务权限。

当前官方预设：在工作台、悬浮式、嵌入式中启用。已有项目可能已经定制，以实际页面为准。

可以把下面的需求发给 Creator：

> 在当前工程中配置「显示 Agent 名称与头像」，保留已有布局和其他功能。先检查所需服务是否可用，完成后说明改了哪里、怎样验证。

## 使用前提

名称、说明和头像只影响展示，不改变连接的 Agent 服务或账号权限。

## 验证结果

在当前项目检查正常、不可用、失败和取消中与此功能相关的状态。涉及附件、语音、登录、历史和恢复时，分别测试实际业务服务；使用 Mock 时注明它是演示数据。

如果只通过类型检查或构建，仍需在页面验证。失败时查看具体提示，不直接清空工程或覆盖已有定制。
