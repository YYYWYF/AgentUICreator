# 回复评价（feedback-actions）

为整次回答提供赞与踩操作，通过项目反馈服务保存评价。

## 分别设置按钮外观 {#分别设置按钮外观}

<span id="example-1"></span>


两个按钮的属性独立配置；保留原有事件处理与反馈服务。

```tsx
import type { ComponentProps } from 'react';
import { ConversationCanonicalResponseFeedbackActions } from '@za38.03/agent-ui-plugins';

export function Example(props: ComponentProps<typeof ConversationCanonicalResponseFeedbackActions>) {
  return <ConversationCanonicalResponseFeedbackActions {...props}
    likeButtonProps={{ ...props.likeButtonProps, size: "sm", side: "top" }}
    dislikeButtonProps={{ ...props.dislikeButtonProps, size: "sm", side: "top" }} />;
}
```

## 禁用负面评价 {#按业务条件禁用负面评价}

示例只禁用踩按钮，赞按钮仍按现有会话与反馈适配决定是否可用。

```tsx
import type { ComponentProps } from 'react';
import { ConversationCanonicalResponseFeedbackActions } from '@za38.03/agent-ui-plugins';

export function Example(props: ComponentProps<typeof ConversationCanonicalResponseFeedbackActions>) {
  return <ConversationCanonicalResponseFeedbackActions {...props}
    dislikeButtonProps={{ ...props.dislikeButtonProps, disabled: true }} />;
}
```

## API

<span id="属性"></span>
<span id="开发-api"></span>

组件：`ConversationCanonicalResponseFeedbackActions`。插件入口将文案变为可选并填入 `conversationFeedback` 默认值；独立使用展示组件时，两个文案必需。无独立展示根节点。

| 插件入口属性 | 类型 | 省略时 / 用途 |
| --- | --- | --- |
| `likeButtonProps?` | `Partial<ConversationTooltipIconButtonProps>` | 点赞按钮的外观、提示、事件与 `icon` |
| `dislikeButtonProps?` | `Partial<ConversationTooltipIconButtonProps>` | 点踩按钮的外观、提示、事件与 `icon` |

没有根级 `className`／`style`。仅在当前会话支持反馈功能时显示按钮。

### 子按钮属性

提示按钮使用 `ConversationTooltipIconButtonProps`，继承 Base UI 按钮属性：

- 状态与事件：`disabled`、`onClick`。
- 内容与样式：`icon`、`className`、`style`。
- 组合与无障碍：`render`、`nativeButton` 和无障碍属性。

组件会叠加运行状态判断，传入 `disabled={false}` 不会解除当前会话的禁用条件。

| 属性 | 类型 | 省略时 / 用途 |
| --- | --- | --- |
| `variant?` | `'default' \| 'outline' \| 'secondary' \| 'ghost' \| 'destructive' \| 'link' \| null` | 按钮样式；各操作按钮可能预设不同值 |
| `size?` | `'default' \| 'xs' \| 'sm' \| 'lg' \| 'icon' \| 'icon-xs' \| 'icon-sm' \| 'icon-lg' \| null` | 按钮尺寸；各操作按钮可能预设不同值 |
| `side?` | `'top' \| 'bottom' \| 'left' \| 'right'` | 默认 `bottom`，提示位置 |

提示按钮默认 `variant="ghost"`、`size="icon"`；普通 `Button` 默认均为 `default`，本插件的预设值以上文为准。普通 `Button` 不包含 `tooltip`、`side`。

默认评价文案只读取 `locales.conversationFeedback.helpful` / `notHelpful`。 所有语言覆盖均需保持 `en-US` / `zh-CN` 对应。

<span id="hook"></span>

评价结果的保存接入项目已有[反馈服务](/development/feedback-service)。自定义反馈入口需要关联整次回答时，在回复页脚作用域调用 `useConversationResponseRuntime()`，读取 `group` 和 `text`，见[保存整次回答](./response-footer#收藏或保存整次回答)。不要用最后一条助理消息代替工具续跑后的完整回答。

<details className="plugin-faq" id="显示评价按钮后结果会自动保存到我的后端吗">
<summary>显示评价按钮后，结果会自动保存到我的后端吗？</summary>

不会。组件通过项目现有反馈适配提交结果；需要在服务接入中实现持久化。按钮属性只负责呈现与交互。

</details>
