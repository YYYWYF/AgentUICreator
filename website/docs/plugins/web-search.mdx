# 查看网页搜索结果（web-search）

把 Agent 的网页搜索结果列在对话中，让用户查看搜到了哪些网页。

## 界面与功能

结果显示可用的网页标题、摘要和来源，用户可以选择结果并打开原网页。搜索本身由 Agent 或业务搜索服务执行。

![查看网页搜索结果（web-search）界面示例](/images/plugins/web-search.png)

## 如何启用和使用

在已创建的工程中启用此 Plugin，放到当前组合支持的位置。可以请 Creator 按下方示例调整；先保留已有页面和其他功能，再检查预览效果。

当前官方预设：未默认加入三种形态，需要按项目需求启用。已有项目可能已经定制，以实际页面为准。

可以把下面的需求发给 Creator：

> 在当前工程中配置「查看网页搜索结果」，保留已有布局和其他功能。先检查所需服务是否可用，完成后说明改了哪里、怎样验证。

## 使用前提

搜索由业务 Agent/服务执行，显示组件不提供搜索后端。用户打开来源前可核对真实地址。

## 属性

优先在项目已有 Plugin 应用文件中设置参数；不需要为了改外观复制官方实现。

| 参数 | 用途 |
| --- | --- |
| `searchProps` | 定制对应区域的 DOM、样式或交互参数。 |
| `renderSearch` | 替换对应内容的展示，保留当前数据与交互。 |
| `Fallback` | 无法展示合法内容时的替代组件。 |

下面是复用公开组件的应用层写法，放在现有组件上下文中使用。`props` 来自该组件公开类型，文案由项目语言配置传入：

```tsx
import type { ComponentProps } from "react";
import { CanonicalWebSearch } from "@za38.03/agent-ui-plugins";

type Props = ComponentProps<typeof CanonicalWebSearch>;
export function ProjectView(props: Props) {
  return <CanonicalWebSearch {...props} />;
}
```

## 验证结果

在当前项目检查正常、不可用、失败和取消中与此功能相关的状态。涉及附件、语音、登录、历史和恢复时，分别测试实际业务服务；使用 Mock 时注明它是演示数据。

如果只通过类型检查或构建，仍需在页面验证。失败时查看具体提示，不直接清空工程或覆盖已有定制。
