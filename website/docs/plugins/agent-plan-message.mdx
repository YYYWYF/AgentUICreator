# 查看计划步骤与完成情况（agent-plan-message）

把 Agent 的执行计划显示为步骤清单，让用户看到准备做什么、正在做哪一步、哪些步骤已完成。

## 界面与功能

例如依次列出「检查代码」「修改界面」「执行验证」。Agent 更新计划时，卡片里的当前步骤和完成标记随之变化。

![查看计划步骤与完成情况（agent-plan-message）界面示例](/images/plugins/agent-plan-message.png)

## 如何启用和使用

在已创建的工程中启用此 Plugin，放到当前组合支持的位置。可以请 Creator 按下方示例调整；先保留已有页面和其他功能，再检查预览效果。

当前官方预设：未默认加入三种形态，需要按项目需求启用。已有项目可能已经定制，以实际页面为准。

可以把下面的需求发给 Creator：

> 在当前工程中配置「查看计划步骤与完成情况」，保留已有布局和其他功能。先检查所需服务是否可用，完成后说明改了哪里、怎样验证。

## 使用前提

需要 Agent 发布计划及更新。前端只展示，不能因为请求结束就把所有步骤显示为完成。

## 属性

优先在项目已有 Plugin 应用文件中设置参数；不需要为了改外观复制官方实现。

| 参数 | 用途 |
| --- | --- |
| `rootProps` | 最外层区域的样式和 DOM 属性。 |
| `planProps` | 定制对应区域的 DOM、样式或交互参数。 |
| `renderPlan` | 替换对应内容的展示，保留当前数据与交互。 |

## 验证结果

在当前项目检查正常、不可用、失败和取消中与此功能相关的状态。涉及附件、语音、登录、历史和恢复时，分别测试实际业务服务；使用 Mock 时注明它是演示数据。

如果只通过类型检查或构建，仍需在页面验证。失败时查看具体提示，不直接清空工程或覆盖已有定制。
