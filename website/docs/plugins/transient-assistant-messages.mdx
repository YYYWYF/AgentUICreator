# 显示临时通知（transient-assistant-messages）

在对话中插入页面提示，例如「连接已恢复」，让用户了解当前页面发生了什么。

## 界面与功能

提示显示在对话的对应位置，但不作为用户问题发送给 Agent，也不写入后端聊天历史。它只保留在当前页面内存中，适合临时通知。

![显示临时通知（transient-assistant-messages）界面示例](/images/plugins/transient-assistant-messages.png)

## 如何启用和使用

在已创建的工程中启用此 Plugin，放到当前组合支持的位置。可以请 Creator 按下方示例调整；先保留已有页面和其他功能，再检查预览效果。

当前官方预设：在工作台、悬浮式、嵌入式中启用。已有项目可能已经定制，以实际页面为准。

可以把下面的需求发给 Creator：

> 在当前工程中配置「显示临时通知」，保留已有布局和其他功能。先检查所需服务是否可用，完成后说明改了哪里、怎样验证。

## 使用前提

仅适合页面提示，不用于冒充业务 Agent 回复。需要持久保存或进入模型上下文的内容应使用业务规定的消息流程。

## 属性

优先在项目已有 Plugin 应用文件中设置参数；不需要为了改外观复制官方实现。

| 参数 | 用途 |
| --- | --- |
| `rootProps` | 最外层区域的样式和 DOM 属性。 |
| `textProps` | 定制对应区域的 DOM、样式或交互参数。 |
| `renderMessage` | 替换对应内容的展示，保留当前数据与交互。 |

## 验证结果

在当前项目检查正常、不可用、失败和取消中与此功能相关的状态。涉及附件、语音、登录、历史和恢复时，分别测试实际业务服务；使用 Mock 时注明它是演示数据。

如果只通过类型检查或构建，仍需在页面验证。失败时查看具体提示，不直接清空工程或覆盖已有定制。
