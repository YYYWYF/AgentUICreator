# 临时通知

## 功能与效果

在聊天中显示“保存成功”“连接已恢复”等操作提示。

### 显示效果

<figure className="plugin-preview">

![聊天中的临时通知](/images/plugins/transient-assistant-messages.png)

<figcaption>通知出现在当前聊天中，可以居中显示，也可以使用用户或助理消息的样式。</figcaption>
</figure>

错误提示会突出显示，方便用户发现操作失败的原因。

新建项目默认启用临时通知。需要显示自己的提示时，把**什么操作后显示、显示什么文字、希望是什么样式**告诉 Creator。例如：

> 保存成功后，在当前聊天中居中显示“保存成功”；保存失败时，用错误样式显示失败原因。

已有项目如果没有这项功能，也可以让 Creator 添加。完成修改后，执行一次保存，检查成功和失败时的提示是否符合预期。

通知只在当前聊天中显示，不会作为问题发送给助理，也不会保存到聊天历史。刷新页面后会消失，默认不会在几秒后自动关闭。

| 可以调整 | 例如 |
| --- | --- |
| 显示时机 | 保存成功、请求失败、连接恢复后显示 |
| 提示文字 | 换成符合业务场景的说明 |
| 呈现方式 | 居中的系统提示、靠左的助理提示、靠右的用户提示，或突出显示的错误提示 |
| 外观 | 字号、文字颜色、背景、圆角和间距 |
| 内容样式 | 增加图标，或换成项目自己的提示样式 |

例如，可以告诉 Creator：“把保存成功提示改成浅绿色背景，加上勾选图标，文字缩小一点。”

需要手动编写接入代码时，见[在对话中显示业务提示](/development/plugin-interaction#临时通知)。
