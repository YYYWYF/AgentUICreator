# 会话服务（conversation-service）

让会话列表、会话切换和历史加载使用同一份会话信息。通常沿用项目现有配置，不需要单独修改。

## 什么时候需要关心

- 列表中有会话，但点击后没有打开对应记录。
- 删除或重命名成功后，列表没有正确更新。
- 加载失败后没有提示，或无法重试。

正常使用时，无需了解服务接口，也不需要另建一套会话管理。

## 怎么让 Creator 修改

描述具体问题和预期结果，例如：

```text
会话列表能显示历史会话，但点击后没有打开对应的聊天记录。
请检查现有历史数据源与会话服务的连接，修复切换问题，
保留页面布局、新建会话和其他会话操作。
加载失败时要有提示，并允许重试。
```

修改后，打开不同的历史会话，确认名称和消息对应正确；再检查失败提示与重试。
