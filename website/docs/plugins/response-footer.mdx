# 使用回复底部操作（response-footer）

在一次完整响应的最终 assistant 消息下只渲染一次操作区。

## 界面与功能

一次完整回复的最后显示一组操作，不会在中间的每段消息下重复出现。

![使用回复底部操作（response-footer）界面示例](/images/plugins/response-footer.png)

截图来源：本项目实际组件的本地 Mock 演示。数据与服务为演示替身。

## 如何启用和使用

在已创建的工程中启用此 Plugin，放到当前组合支持的位置。可以请 Creator 按下方示例调整；先保留已有页面和其他功能，再检查预览效果。

当前官方预设：在工作台、悬浮式、嵌入式中启用。已有项目可能已经定制，以实际页面为准。

可以把下面的需求发给 Creator：

> 在当前工程中配置「使用回复底部操作」，保留已有布局和其他功能。先检查所需服务是否可用，完成后说明改了哪里、怎样验证。

## 使用前提

复制、重试、评价与导出按项目选择组合。开发者追加动作时保留已有功能，避免重复显示。

## 属性

优先在项目已有 Plugin 应用文件中设置参数；不需要为了改外观复制官方实现。

| 参数 | 用途 |
| --- | --- |
| `children` | 替换或补充组件内容。 |
| `rootProps` | 最外层区域的样式和 DOM 属性。 |
| `actionBarProps` | 定制对应区域的 DOM、样式或交互参数。 |
| `branchPickerProps` | 定制对应区域的 DOM、样式或交互参数。 |

下面是复用公开组件的应用层写法，放在现有组件上下文中使用。`props` 来自该组件公开类型，文案由项目语言配置传入：

```tsx
import type { ComponentProps } from "react";
import { ConversationCanonicalResponseFooter } from "@za38.03/agent-ui-plugins";

type Props = ComponentProps<typeof ConversationCanonicalResponseFooter>;
export function ProjectView(props: Props) {
  return <ConversationCanonicalResponseFooter {...props} />;
}
```

## 验证结果

在当前项目检查正常、不可用、失败和取消中与此功能相关的状态。涉及附件、语音、登录、历史和恢复时，分别测试实际业务服务；使用 Mock 时注明它是演示数据。

如果只通过类型检查或构建，仍需在页面验证。失败时查看具体提示，不直接清空工程或覆盖已有定制。
