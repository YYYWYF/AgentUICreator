# 复制回复（copy-action）

提供复制按钮，把 Agent 当前这次完整回复复制到剪贴板。

## 界面与功能

回复完成后点击复制，即可把文本粘贴到其他地方。一次回复分成多条消息时，会按这次回复一起复制。

![复制回复（copy-action）界面示例](/images/plugins/copy-action.png)

## 如何启用和使用

在已创建的工程中启用此 Plugin，放到当前组合支持的位置。可以请 Creator 按下方示例调整；先保留已有页面和其他功能，再检查预览效果。

当前官方预设：在工作台、悬浮式、嵌入式中启用。已有项目可能已经定制，以实际页面为准。

可以把下面的需求发给 Creator：

> 在当前工程中配置「复制回复」，保留已有布局和其他功能。先检查所需服务是否可用，完成后说明改了哪里、怎样验证。

## 使用前提

浏览器需要允许剪贴板写入，某些部署要求安全上下文与用户点击。复制针对当前完整回复，不是整个历史。

## 属性

优先在项目已有 Plugin 应用文件中设置参数；不需要为了改外观复制官方实现。

| 参数 | 用途 |
| --- | --- |
| `style` | 局部尺寸或样式。 |
| `disabled` | 按业务条件限制交互。 |
| `className` | 沿用工程样式命名设置外观。 |
| `children` | 替换或补充组件内容。 |
| `onClick` | 自定义点击反馈，保留原有默认动作。 |

下面是复用公开组件的应用层写法，放在现有组件上下文中使用。`props` 来自该组件公开类型，文案由项目语言配置传入：

```tsx
import type { ComponentProps } from "react";
import { ConversationCanonicalResponseCopyAction } from "@za38.03/agent-ui-plugins";

type Props = ComponentProps<typeof ConversationCanonicalResponseCopyAction>;
export function ProjectView(props: Props) {
  return <ConversationCanonicalResponseCopyAction {...props} />;
}
```

## 验证结果

在当前项目检查正常、不可用、失败和取消中与此功能相关的状态。涉及附件、语音、登录、历史和恢复时，分别测试实际业务服务；使用 Mock 时注明它是演示数据。

如果只通过类型检查或构建，仍需在页面验证。失败时查看具体提示，不直接清空工程或覆盖已有定制。
