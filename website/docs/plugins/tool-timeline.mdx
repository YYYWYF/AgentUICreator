# 工具执行时间线（tool-timeline）

## 功能与效果

<figure className="plugin-preview">

![调用时间线界面](/images/plugins/tool-timeline.jpg)

<figcaption>展开后的时间线列出 3 次读取操作和实际文件路径；标题继续汇总当前工具活动。</figcaption>
</figure>

将当前助理消息中的工具活动汇总为可展开的执行时间线，自动更新调用摘要、执行目标和可用的文件变更统计。

### 自动汇总工具活动

存在可进入通用摘要的工具调用时，插件显示时间线入口。步骤来自当前消息中的真实工具调用，按 `toolCallId` 区分。

带有专用展示、嵌套消息或其他独立展示信息的工具会参与不同的展示路径；如果消息中没有可作为通用时间线入口的调用，时间线不会单独出现。

### 运行中和结束后的摘要

有工具仍在运行时，标题显示活动中的调用摘要；工具停止运行后，标题切换为结果摘要。只有所有调用都完成时才使用完成摘要，未完成的调用不会被统一描述为成功。

已完成的文件编辑工具如果提供文件名和增加、删除行数，插件会按文件汇总这些数据。没有统计数据时只显示调用摘要。

### 展开查看执行步骤

时间线默认收起，点击标题展开步骤列表。插件按已知工具名显示读取、编辑、命令或搜索图标，并从调用参数中取得文件路径、命令或检索词；其他工具显示自己的名称。

用户切换展开状态不会重新执行工具。错误、审批、中断和多模态结果等需要独立展示的内容，仍由对应的工具详情呈现，时间线不会替代这些操作入口。

## 数据来源与显示条件

### 从工具调用取得时间线 {#显示条件与数据来源}

时间线消费当前回复的工具调用和运行状态。下面列出读取和编辑文件的工具事件；通用运行事件和 SSE 包装见[通用工具事件](./ag-ui-data#通用工具事件)：

```jsonl
{"type":"TOOL_CALL_START","toolCallId":"read-1","toolCallName":"read_file"}
{"type":"TOOL_CALL_ARGS","toolCallId":"read-1","delta":"{\"path\":\"src/main.tsx\"}"}
{"type":"TOOL_CALL_END","toolCallId":"read-1"}
{"type":"TOOL_CALL_RESULT","messageId":"read-result-1","toolCallId":"read-1","role":"tool","content":"{\"content\":\"export const title = 'Agent UI';\"}"}
{"type":"TOOL_CALL_START","toolCallId":"edit-1","toolCallName":"edit_file"}
{"type":"TOOL_CALL_ARGS","toolCallId":"edit-1","delta":"{\"path\":\"src/main.tsx\"}"}
{"type":"TOOL_CALL_END","toolCallId":"edit-1"}
{"type":"TOOL_CALL_RESULT","messageId":"edit-result-1","toolCallId":"edit-1","role":"tool","content":"{\"file\":\"src/main.tsx\",\"added\":8,\"removed\":2}"}
```

不同调用使用不同 `toolCallId`，参数和结果按这个 ID 关联。运行期间，时间线显示活动摘要；工具结果到达后更新完成情况。`TOOL_CALL_END` 只结束参数流，不能代替工具结果或把调用标成成功。

工具名用于选择读取、编辑、命令或搜索图标，参数中的 `path`、`command`、`query` 等字符串用于显示执行目标；其他工具仍以自己的名称展示。无需另传 `steps` 或前端图标名称。

文件变更统计来自已完成编辑工具的结果：`file` 为非空文件名，`added`、`removed` 是可选的非负整数；同一文件的有效统计会累计。省略这些字段时不显示变更行数，不影响普通步骤展示。

至少需要存在可进入通用摘要的调用，时间线才有展示入口。已注册的专用工具和子任务可以自行展示状态，不一定单独建立通用时间线；错误、审批、中断和媒体结果仍保留对应详情。单独发送一段工具名称文字或一份前端步骤数组，不会建立这些工具调用。

### 初始展开并限制列表长度 {#默认展开并限制步骤数}

<span id="example-1"></span>

希望直接展示执行过程时，在已有时间线入口设置初始展开，并将可见步骤限制为前 5 项：

```tsx
import type { ComponentProps } from 'react';
import { ConversationToolTimelinePlugin as Implementation } from '@za38.03/agent-ui-plugins/tool-timeline';
import { usePluginRenderScope } from '@za38.03/agent-ui-plugins';

export function ConversationToolTimelinePlugin(props: ComponentProps<typeof Implementation>) {
  const scope = usePluginRenderScope<Partial<ComponentProps<typeof Implementation>>>();
  if (scope?.kind !== 'conversation.tool-timeline') return null;
  return <Implementation {...scope.value} {...props}
    defaultExpanded
    visibleSteps={5} />;
}
```

限制的是已接收步骤的展示数量，摘要仍依据实际调用生成；不会分页请求、截断执行或改变任务状态。需要完整列表时省略 `visibleSteps`。

### API

以下选项用于定制当前消息中的展示。显示条件、活动状态和消息内容继续由原有会话环境提供。



继承 `div` 原生属性，排除默认 `children` 定义。

| 属性 | 类型 | 省略时 / 用途 |
| --- | --- | --- |
| `expanded?` | `boolean` | 受控展开 |
| `defaultExpanded?` | `boolean` | 默认 `false` |
| `onExpandedChange?` | `(expanded: boolean) => void` | 展开变化通知 |
| `visibleSteps?` | `number` | 默认全部步骤 |

步骤来自当前助手消息的工具调用，不通过此属性表创建工具或新的运行状态。

摘要与进行中文案统一在 `locales.toolTimeline` 修改；保留 `{count}`、`{files}` 等占位符。 所有语言覆盖均需保持 `en-US` / `zh-CN` 对应。
