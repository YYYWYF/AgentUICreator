# 查看工具详情与执行确认（tool-fallback）

为没有专用界面的工具显示调用详情：操作名称、输入参数、返回结果，以及需要时的执行确认。

## 界面与功能

工具调用是 Agent 发起的一次具体操作，例如读取项目配置。点击工具名称可展开参数、结果或错误；需要确认的操作会提供允许或拒绝入口。工具组负责归类多次调用，本插件负责展示其中每一次调用的内容。

下图的 `read_config` 调用读取了 `app-ui/app-ui.json`，卡片同时展示传入的文件路径和返回的配置结果。调用失败时，这里会显示错误原因。

![展开工具调用，查看输入参数和返回结果](/images/plugins/tool-fallback.png)

如果某次操作需要用户确认，卡片会先展示待执行的操作和参数，再提供「允许」与「拒绝」入口；用户可以先看清内容，再作决定。

![工具等待用户确认，展示操作参数和允许拒绝按钮](/images/plugins/tool-fallback-approval.png)

## 如何启用和使用

在已创建的工程中启用此 Plugin，放到当前组合支持的位置。可以请 Creator 按下方示例调整；先保留已有页面和其他功能，再检查预览效果。

当前官方预设：在工作台、悬浮式、嵌入式中启用。已有项目可能已经定制，以实际页面为准。

可以把下面的需求发给 Creator：

> 在当前工程中配置「查看工具详情与执行确认」，保留已有布局和其他功能。先检查所需服务是否可用，完成后说明改了哪里、怎样验证。

## 使用前提

自定义显示时保留原有审批和问题入口。收到工具调用不表示已执行，历史查看不能再次触发业务操作。

## 属性

优先在项目已有 Plugin 应用文件中设置参数；不需要为了改外观复制官方实现。

| 参数 | 用途 |
| --- | --- |
| `rootProps` | 最外层区域的样式和 DOM 属性。 |
| `triggerProps` | 定制对应区域的 DOM、样式或交互参数。 |
| `contentProps` | 定制对应区域的 DOM、样式或交互参数。 |
| `argsProps` | 定制对应区域的 DOM、样式或交互参数。 |
| `resultProps` | 定制对应区域的 DOM、样式或交互参数。 |
| `errorProps` | 定制对应区域的 DOM、样式或交互参数。 |
| `approvalProps` | 定制对应区域的 DOM、样式或交互参数。 |
| `children` | 替换或补充组件内容。 |

## 验证结果

在当前项目检查正常、不可用、失败和取消中与此功能相关的状态。涉及附件、语音、登录、历史和恢复时，分别测试实际业务服务；使用 Mock 时注明它是演示数据。

如果只通过类型检查或构建，仍需在页面验证。失败时查看具体提示，不直接清空工程或覆盖已有定制。
