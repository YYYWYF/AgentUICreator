# 文档检索片段（retrieval-chunks）

例如搜索退款规则后，卡片显示命中的文档、相关段落及可用的评分等信息；有多个结果时可逐项查看。

日常调整可以交给 Creator；需要自己写代码时，直接查看[手动开发](#手动开发)。

![查看文档检索片段（retrieval-chunks）界面示例](/images/plugins/retrieval-chunks.png)

## 启用与使用

在 **Creator 输入框**输入 `/enable retrieval-chunks`，点击下图中的 **「查看文档检索片段」**。

![Creator 启用菜单：点击「查看文档检索片段」，插件 ID 为 retrieval-chunks](/images/plugins/enable/retrieval-chunks.jpg)

## 定制选项

| 可以改什么 | 效果 |
| --- | --- |
| 一次显示几条片段 | 限制卡片中同时展示的结果数量。 |
| 搜索提示 | 修改检索中、已找到片段等提示文字。 |
| 卡片样式 | 调整宽度、间距、字号和背景。 |
| 整个片段列表 | 自定义文档名称、原文片段和出处的排列。 |

## 需求示例

```text
请修改「查看文档检索片段（retrieval-chunks）」：
修改：同时展示【3】条片段，卡片字号设为【13px】，间距设为【12px】。
保留：真实片段内容、出处和原有浏览操作。
```

## 手动开发

打开项目中的 `plugins/retrieval-chunks/index.tsx`，在已有公开组件调用处设置属性或调整组合。修改外观时，保留文件中读取会话状态、调用服务、显示子插件和注册消息组件的代码。

### 属性

`?` 表示可选；“省略时”描述当前组件行为。`ReactNode`、`CSSProperties`、`ComponentProps` 等为 React 类型；完整类型以项目实际安装版本为准。

组件：`CanonicalRetrievalChunks`；类型：`RetrievalChunksPluginProps`。还接受下方列出的工具调用数据、样式和无障碍属性。

| 属性 | 类型 | 省略时 / 用途 |
| --- | --- | --- |
| `query?` | `string` | 默认工具输入中的 `query`，没有时为空字符串 |
| `chunks?` | `readonly RetrievalChunk[]` | 默认从结果读取片段，运行中可为空 |
| `searching?` | `boolean` | 默认按工具是否正在运行推导 |
| `visibleCount?` | `number` | 默认展示全部片段 |
| `renderRetrieval?` | `(props: RetrievalChunksProps, tool: ConversationToolCallProps) => ReactNode` | 自定义整个检索组件 |
| `Fallback?` | `ComponentType<ConversationToolCallProps>` | 默认 `ConversationToolFallback` |

`RetrievalChunk` 为 `{ id: string; source: string; locator: string; score: number; text: string }`。原始工具数据仍先经过校验，再应用自定义展示属性。

#### 外观与无障碍属性

以下属性均可选。

| 属性 | 类型 | 用途 |
| --- | --- | --- |
| `className` | `string` | 整体样式类 |
| `style` | `CSSProperties` | 整体内联样式 |
| `id` | `string` | 元素标识 |
| `role` | `HTMLAttributes<HTMLElement>['role']` | 无障碍角色 |
| `aria-label` | `string` | 无障碍名称 |
| `aria-describedby` | `string` | 描述元素 ID |
| `onClick` | `MouseEventHandler<HTMLElement>` | 点击回调 |

#### 当前工具调用的数据与操作

这些数据和方法由现有会话传入，类型为 `ConversationToolCallProps`。`toolCallId`、`toolName`、`args`、`status` 是必需字段，其余已列出的字段可选；修改展示时保留原有传参。

| 属性 | 类型 | 用途 |
| --- | --- | --- |
| `type?` | `'tool-call'` | 消息片段类型 |
| `toolCallId` | `string` | 工具调用 ID |
| `toolName` | `string` | 工具名称 |
| `args` | `unknown` | 解析后的输入参数 |
| `argsText?` | `string` | 输入参数的文本形式 |
| `result?` | `unknown` | 工具结果 |
| `messages?` | `readonly ConversationMessage[]` | 关联的嵌套消息 |
| `isError?` | `boolean` | 结果是否为错误 |
| `status` | `ConversationToolCallStatus` | 工具当前状态：运行中、已完成、未完成或等待用户操作 |
| `addResult?` | `(result: unknown) => void` | 提交前端工具结果 |
| `resumeInterrupt?` | `(payload: unknown) => Promise<void>` | 提交恢复数据，让暂停的任务继续执行 |
| `decisionRequest?` | `ConversationCommandDecisionRequest` | 运行环境提供的操作确认请求 |
| `submitDecision?` | `(decisionType: string) => Promise<void>` | 提交后端支持的决定 |

`ConversationToolCallStatus` 为 `{ type: 'running' }`、`{ type: 'complete' }`、`{ type: 'incomplete'; reason?: string; error?: unknown }` 或 `{ type: 'requires-action'; reason?: string }`。`ConversationCommandDecisionRequest` 含 `allowedDecisions: readonly string[]` 和可选 `description: string`。

该类型允许传入额外字段，但字段是否生效取决于组件实现，不能据此添加任意配置项。

### 类型查询

可在编辑器中通过公开组件取得完整属性类型：

```ts
import type { ComponentProps } from 'react';
import type { CanonicalRetrievalChunks } from '@za38.03/agent-ui-plugins';

type ImplementationProps = ComponentProps<typeof CanonicalRetrievalChunks>;
```

组件定制方式见[组件定制指南](/development/component-customization)；配置位置和子插件顺序见[布局与插件组合](/development/layout-and-composition)。

检索状态与评分文案统一在 `locales.searchTools` 修改：`retrieving`、`passages`、`relevance`、`score`。检索内容仍是工具数据。 所有语言覆盖均需保持 `en-US` / `zh-CN` 对应。
