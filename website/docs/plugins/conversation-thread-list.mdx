# 查找与切换会话（conversation-thread-list）

在侧栏列出已有会话，让用户查找并切换不同的聊天记录。

## 界面与功能

点击一条记录即可打开那段对话。接好历史服务后，还可以搜索会话，并使用项目提供的删除入口。

![查找与切换会话（conversation-thread-list）界面示例](/images/plugins/conversation-thread-list.png)

## 如何启用和使用

在已创建的工程中启用此 Plugin，放到当前组合支持的位置。可以请 Creator 按下方示例调整；先保留已有页面和其他功能，再检查预览效果。

当前官方预设：在工作台、悬浮式、嵌入式中启用。已有项目可能已经定制，以实际页面为准。

可以把下面的需求发给 Creator：

> 在当前工程中配置「查找与切换会话」，保留已有布局和其他功能。先检查所需服务是否可用，完成后说明改了哪里、怎样验证。

## 使用前提

开发者需接入历史服务，明确列表、详情和删除能力。只读历史与可继续会话不同。

## 属性

优先在项目已有 Plugin 应用文件中设置参数；不需要为了改外观复制官方实现。

| 参数 | 用途 |
| --- | --- |
| `rootProps` | 最外层区域的样式和 DOM 属性。 |
| `listProps` | 定制对应区域的 DOM、样式或交互参数。 |
| `children` | 替换或补充组件内容。 |
| `onRefresh` | 监听对应操作，按已安装类型处理回调。 |

## 验证结果

在当前项目检查正常、不可用、失败和取消中与此功能相关的状态。涉及附件、语音、登录、历史和恢复时，分别测试实际业务服务；使用 Mock 时注明它是演示数据。

如果只通过类型检查或构建，仍需在页面验证。失败时查看具体提示，不直接清空工程或覆盖已有定制。
