# 查看图表（chart-message）

把 Agent 返回的数值数据画成图表，方便比较不同项目的大小。

## 界面与功能

例如把四个季度的销售额显示为条形图，同时保留项目名称和数值，用户不用只阅读一段数字。

![查看图表（chart-message）界面示例](/images/plugins/chart-message.png)

## 如何启用和使用

在已创建的工程中启用此 Plugin，放到当前组合支持的位置。可以请 Creator 按下方示例调整；先保留已有页面和其他功能，再检查预览效果。

当前官方预设：未默认加入三种形态，需要按项目需求启用。已有项目可能已经定制，以实际页面为准。

可以把下面的需求发给 Creator：

> 在当前工程中配置「查看图表」，保留已有布局和其他功能。先检查所需服务是否可用，完成后说明改了哪里、怎样验证。

## 使用前提

需返回符合组件要求的数据，并加载项目图表样式。正确显示不等于数据计算正确，仍需检查单位与来源。

## 属性

优先在项目已有 Plugin 应用文件中设置参数；不需要为了改外观复制官方实现。

| 参数 | 用途 |
| --- | --- |
| `rootProps` | 最外层区域的样式和 DOM 属性。 |
| `captionProps` | 定制对应区域的 DOM、样式或交互参数。 |
| `listProps` | 定制对应区域的 DOM、样式或交互参数。 |
| `itemProps` | 定制对应区域的 DOM、样式或交互参数。 |
| `labelProps` | 定制对应区域的 DOM、样式或交互参数。 |
| `trackProps` | 定制对应区域的 DOM、样式或交互参数。 |
| `barProps` | 定制对应区域的 DOM、样式或交互参数。 |
| `valueProps` | 定制对应区域的 DOM、样式或交互参数。 |
| `renderItem` | 替换对应内容的展示，保留当前数据与交互。 |
| `renderChart` | 替换对应内容的展示，保留当前数据与交互。 |

下面是复用公开组件的应用层写法，放在现有组件上下文中使用。`props` 来自该组件公开类型，文案由项目语言配置传入：

```tsx
import type { ComponentProps } from "react";
import { CanonicalChartMessage } from "@za38.03/agent-ui-plugins";

type Props = ComponentProps<typeof CanonicalChartMessage>;
export function ProjectView(props: Props) {
  return <CanonicalChartMessage {...props} />;
}
```

## 验证结果

在当前项目检查正常、不可用、失败和取消中与此功能相关的状态。涉及附件、语音、登录、历史和恢复时，分别测试实际业务服务；使用 Mock 时注明它是演示数据。

如果只通过类型检查或构建，仍需在页面验证。失败时查看具体提示，不直接清空工程或覆盖已有定制。
