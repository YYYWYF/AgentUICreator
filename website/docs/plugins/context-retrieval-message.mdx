# 查看上下文检索结果（context-retrieval-message）

展示 AG-UI CUSTOM 事件中的上下文检索结果。

## 界面与功能

对话中显示此次提供给 Agent 的上下文检索分组与片段，用户可展开阅读。

![查看上下文检索结果（context-retrieval-message）界面示例](/images/plugins/context-retrieval-message.png)

截图来源：本项目实际组件的本地 Mock 演示。数据与服务为演示替身。

## 如何启用和使用

在已创建的工程中启用此 Plugin，放到当前组合支持的位置。可以请 Creator 按下方示例调整；先保留已有页面和其他功能，再检查预览效果。

当前官方预设：在工作台、悬浮式、嵌入式中启用。已有项目可能已经定制，以实际页面为准。

可以把下面的需求发给 Creator：

> 在当前工程中配置「查看上下文检索结果」，保留已有布局和其他功能。先检查所需服务是否可用，完成后说明改了哪里、怎样验证。

## 使用前提

需要相应上下文检索数据，与普通工具的文档检索结果分别接入。显示卡片不代表用户可访问所有原文。

## 验证结果

在当前项目检查正常、不可用、失败和取消中与此功能相关的状态。涉及附件、语音、登录、历史和恢复时，分别测试实际业务服务；使用 Mock 时注明它是演示数据。
