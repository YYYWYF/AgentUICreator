# 新建会话（conversation-new）

创建新的会话身份并通过 当前会话/现有 Host 导航。

## 界面与功能

点击新建后进入空会话，输入区、建议和列表选择同步到新记录。

![新建会话（conversation-new）界面示例](/images/plugins/conversation-new.png)

截图来源：本项目实际组件的本地 Mock 演示。数据与服务为演示替身。

## 如何启用和使用

在会话列表或现有页面的新建入口创建对话。开发者加入此能力后，检查新建后输入区和列表是否指向新会话。

当前官方预设：在工作台、悬浮式、嵌入式中启用。已有项目可能已经定制，以实际页面为准。

可以把下面的需求发给 Creator：

> 在当前工程中配置「新建会话」，保留已有布局和其他功能。先检查所需服务是否可用，完成后说明改了哪里、怎样验证。

## 使用前提

新建不删除旧历史。无持久服务时不承诺刷新后能找回新对话。

## 验证结果

在当前项目检查正常、不可用、失败和取消中与此功能相关的状态。涉及附件、语音、登录、历史和恢复时，分别测试实际业务服务；使用 Mock 时注明它是演示数据。

如果只通过类型检查或构建，仍需在页面验证。失败时查看具体提示，不直接清空工程或覆盖已有定制。
