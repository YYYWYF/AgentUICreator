## 文字按钮与右侧提示 {#文字按钮与右侧提示}

入口大小通过 buttonProps.style 设置，提示的位置由 tooltipContentProps 设置。buttonProps 使用原生按钮属性，没有 size/variant 属性。

```tsx
import type { ComponentProps } from 'react';
import { CanonicalConversationNew } from '@za38.03/agent-ui-plugins';

export function Example(props: ComponentProps<typeof CanonicalConversationNew>) {
  return <CanonicalConversationNew {...props}
    showLabel
    buttonProps={{ ...props.buttonProps, style: { ...props.buttonProps?.style, paddingInline: 12, minHeight: 32 } }}
    tooltipContentProps={{ ...props.tooltipContentProps, side: "right" }} />;
}
```

## 业务入口新建会话 {#从业务工具栏新建会话}

把按钮放到现有插件中；`label` 由项目文案提供，`onError` 接已有错误提示。点击调用现有新建动作，不用自己生成 threadId。

```tsx
import { useState } from 'react';
import { usePluginActions } from '@za38.03/agent-ui-plugins';

export function NewConversationAction({ label, onError }: {
  label: string;
  onError: (error: unknown) => void;
}) {
  const actions = usePluginActions();
  const [pending, setPending] = useState(false);
  return <button type="button" disabled={pending} onClick={async () => {
    if (pending) return;
    setPending(true);
    try { await actions.startNewConversation(); }
    catch (error: unknown) { onError(error); }
    finally { setPending(false); }
  }}>{label}</button>;
}
```

等待期间禁用重复点击；完成后由原 Host 切换到新对话，历史会话仍由原来的列表和 Runtime 管理。

## API

<span id="属性"></span>
<span id="开发-api"></span>

在 `CanonicalConversationNew` 上设置以下属性。

继承外层 `div` 原生属性，排除 children 与 onClick。点击回调统一使用 buttonProps.onClick。

| 属性 | 类型 | 省略时 / 用途 |
| --- | --- | --- |
| `icon?` | `ReactNode` | 自定义按钮图标 |
| `showLabel?` | `boolean` | 组件默认 `true`；部分初始化模板设置为 `false`，仅显示图标但保留无障碍名称 |
| `disabled?` | `boolean` | 禁用新建按钮 |
| `buttonProps?` | `Omit<ComponentProps<typeof ConversationThreadListNew>, 'children' \| 'disabled'>` | 按钮属性，保留默认新建与导航行为 |
| `tooltipProps?` | `Omit<ComponentProps<typeof AgentUITooltip>, 'children'>` | 提示根组件配置 |
| `tooltipContentProps?` | `Omit<ComponentProps<typeof AgentUITooltipContent>, 'children'>` | 提示位置与外观配置，内容沿用 locale |

<span id="hook"></span>

业务工具栏需要添加自己的“新建会话”入口时，从 `@za38.03/agent-ui-plugins` 调用 `usePluginActions().startNewConversation()`，放在已有插件组件内，见示例。

需要导航到已有记录时，从同一入口导入 `useConversationNavigation()`，返回 `ConversationNavigation`：

| 方法 | 参数与返回值 | 调用结果 |
| --- | --- | --- |
| `switchToThread(threadId)` | `(string) → Promise<unknown>` | 切换到指定 Thread；调用方等待导航并处理失败 |
| `switchToNewThread()` | `() → Promise<unknown>` | 进入新会话；普通插件新建优先使用前面的插件动作 |
| `reloadCurrentThread()` | `() → Promise<void>` | 重新加载当前 Thread；不等于重新生成一条回答 |

不要在组件渲染或订阅回调里新建会话。当前 Thread、业务路由与后台运行的关系见[多个助理](/development/multiple-agents)。

<details className="plugin-faq" id="新建会话会停止后台的对话吗">
<summary>新建会话会停止后台的对话吗？</summary>

新建创建独立 Thread。已挂载的后台会话沿用已有生命周期；需要停止时使用对应会话的停止操作。

</details>
