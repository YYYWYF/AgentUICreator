# 查看账号与退出登录（auth-account）

显示当前用户的账号信息，并在接入认证服务后提供退出登录入口。

## 界面与功能

例如在侧栏底部显示用户名和头像，点击后打开账号菜单。只传入用户资料时展示身份；接入认证会话后，菜单还可以提供退出登录。

![查看账号与退出登录（auth-account）界面示例](/images/plugins/auth-account.png)

## 如何启用和使用

由开发者接好现有账号服务，配置登录和退出操作。用户查看当前账号并按业务登录流程操作。

当前官方预设：未默认加入三种形态，需要按项目需求启用。已有项目可能已经定制，以实际页面为准。

可以把下面的需求发给 Creator：

> 在当前工程中配置「查看账号与退出登录」，保留已有布局和其他功能。先检查所需服务是否可用，完成后说明改了哪里、怎样验证。

## 使用前提

登录、退出和会话刷新由业务认证服务实现。用户资料仅用于展示，不能作为请求授权凭据。

## 验证结果

在当前项目检查正常、不可用、失败和取消中与此功能相关的状态。涉及附件、语音、登录、历史和恢复时，分别测试实际业务服务；使用 Mock 时注明它是演示数据。

如果只通过类型检查或构建，仍需在页面验证。失败时查看具体提示，不直接清空工程或覆盖已有定制。
