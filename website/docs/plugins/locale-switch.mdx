# 切换界面语言（locale-switch）

提供中英文切换控件，切换按钮、提示和菜单等界面文字的语言。

## 界面与功能

切换语言后，当前对话和输入草稿会保留。它控制界面语言，Agent 用什么语言回答由 Agent 和业务配置决定。

![切换界面语言（locale-switch）界面示例](/images/plugins/locale-switch.png)

## 如何启用和使用

开发者启用语言按钮与应用语言设置。用户从该入口选择中文或英文；受控宿主收到 onLocaleChange 后更新 locale。

当前官方预设：未默认加入三种形态，需要按项目需求启用。已有项目可能已经定制，以实际页面为准。

可以把下面的需求发给 Creator：

> 在当前工程中配置「切换界面语言」，保留已有布局和其他功能。先检查所需服务是否可用，完成后说明改了哪里、怎样验证。

## 使用前提

开发者需启用语言设置。受控页面在用户选择后更新 locale，否则显示会回到 Host 传入的值。

在已有 React 页面中控制语言：

```tsx
<Agent locale={locale} onLocaleChange={setLocale} />
```

## 验证结果

在当前项目检查正常、不可用、失败和取消中与此功能相关的状态。涉及附件、语音、登录、历史和恢复时，分别测试实际业务服务；使用 Mock 时注明它是演示数据。

如果只通过类型检查或构建，仍需在页面验证。失败时查看具体提示，不直接清空工程或覆盖已有定制。
