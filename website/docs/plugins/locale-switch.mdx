# 界面语言切换（locale-switch）

切换语言后，当前对话和输入草稿会保留。它控制界面语言，Agent 用什么语言回答由 Agent 和业务配置决定。

日常调整可以交给 Creator；需要自己写代码时，直接查看[手动开发](#手动开发)。

![切换界面语言（locale-switch）界面示例](/images/plugins/locale-switch.png)

## 启用与使用

在 **Creator 输入框**输入 `/enable locale-switch`，点击下图中的 **「切换界面语言」**。

![Creator 启用菜单：点击「切换界面语言」，插件 ID 为 locale-switch](/images/plugins/enable/locale-switch.jpg)

开发者启用语言按钮与应用语言设置。用户从该入口选择中文或英文；受控宿主收到 onLocaleChange 后更新 locale。

## 定制选项

页面语言参数见[语言配置](/development/agent-options#界面语言切换)。控件属性如下：

| 可以改什么 | 效果 |
| --- | --- |
| 选择框大小和外观 | 调整大小、宽度、颜色和边框。 |
| 周围的间距 | 调整选择框与周围内容的距离。 |
| 选项文字 | 修改“中文”“English”等显示文字，保留对应语言代码。 |

## 需求示例

```text
请修改「切换界面语言（locale-switch）」：
修改：中文选项显示为【简体中文】，英文选项显示为【English】，选择框宽度设为【120px】。
保留：zh-CN、en-US 语言代码和切换行为。
```

## 手动开发

打开项目中的 `plugins/locale-switch/index.tsx`，在已有公开组件调用处设置属性或调整组合。修改外观时，保留文件中读取会话状态、调用服务、显示子插件和注册消息组件的代码。

### 属性

`?` 表示可选；“省略时”描述当前组件行为。`ReactNode`、`CSSProperties`、`ComponentProps` 等为 React 类型；完整类型以项目实际安装版本为准。

组件：`CanonicalLocaleSwitchPlugin`；类型：`LocaleSwitchPluginProps`。继承 `section` 原生属性。

| 属性 | 类型 | 省略时 / 用途 |
| --- | --- | --- |
| `locale?` | `AgentUILocaleCode` | 受控语言，优先于服务快照；均未提供时读取统一语言上下文 |
| `onLocaleChange?` | `(locale: AgentUILocaleCode) => void` | 受控变化回调，优先于服务的 `setLocale` |
| `service?` | `{ getSnapshot(): { locale: AgentUILocaleCode }; subscribe(listener: () => void): () => void; setLocale(locale: AgentUILocaleCode): void }` | 已有语言服务 |
| `contextId?` | `string` | 默认 `locale`，选择框 ID 为 `${contextId}-control` |
| `disabled?` | `boolean` | 选择框禁用设置 |
| `selectProps?` | `ComponentProps<typeof NativeSelect>` | 原生下拉框属性；`onChange` 先调用，`preventDefault()` 可阻止默认切换 |
| `children?` | `ReactNode` | 替换默认语言选项 |

`AgentUILocaleCode` 为 `'zh-CN' | 'en-US'`。没有变化回调且没有可用服务时，组件不显示。

#### 原生属性

支持本节注明的元素／根组件原生 React 属性，包括 `className?: string`、`style?: CSSProperties`、`id?: string`、`role`、`aria-*`、`data-*` 和相应事件回调；排除项与单独定义的属性以上文为准。

#### 子插件渲染

这些参数属于插件通用接口，由插件运行环境（Runtime）提供。当前组件没有调用它们；修改外观时使用上方的展示属性即可。

| 属性 | 类型 | 用途 |
| --- | --- | --- |
| `renderSlot?` | `(name: string, fallback?: ReactNode) => ReactNode` | 按插槽名称显示子插件；当前组件未调用此函数 |
| `renderScopedSlot?` | `(name: string, scope: { kind: string; value: unknown }, fallback?: ReactNode) => ReactNode` | 显示子插件并传入本次渲染的数据；当前组件未调用此函数 |

参数说明：

- `name`：插槽名称，决定在哪个位置显示子插件。
- `fallback`：该位置没有可用子插件时显示的备用内容。
- `scope`：本次渲染的数据。`kind` 标识数据类型，`value` 存放具体数据，例如当前工具调用或推理分组。不同类型仍使用同一个 `renderScopedSlot`。

### 类型查询

可在编辑器中通过公开组件取得完整属性类型：

```ts
import type { ComponentProps } from 'react';
import type { CanonicalLocaleSwitchPlugin } from '@za38.03/agent-ui-plugins';

type ImplementationProps = ComponentProps<typeof CanonicalLocaleSwitchPlugin>;
```

组件定制方式见[组件定制指南](/development/component-customization)；配置位置和子插件顺序见[布局与插件组合](/development/layout-and-composition)。
