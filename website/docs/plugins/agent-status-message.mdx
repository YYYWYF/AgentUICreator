# 查看 Agent 状态（agent-status-message）

在对话中显示 Agent 当前阶段和状态结果。

## 界面与功能

对话里出现状态卡片，说明当前阶段或结果，失败不会显示成完成。

![查看 Agent 状态（agent-status-message）界面示例](/images/plugins/agent-status-message.png)

截图来源：[assistant-ui 上游示例](https://www.assistant-ui.com/elements/agent-status)。用于展示对应组件；本项目的样式与组合以实际工程为准。

## 如何启用和使用

在已创建的工程中启用此 Plugin，放到当前组合支持的位置。可以请 Creator 按下方示例调整；先保留已有页面和其他功能，再检查预览效果。

当前官方预设：未默认加入三种形态，需要按项目需求启用。已有项目可能已经定制，以实际页面为准。

可以把下面的需求发给 Creator：

> 在当前工程中配置「查看 Agent 状态」，保留已有布局和其他功能。先检查所需服务是否可用，完成后说明改了哪里、怎样验证。

## 使用前提

需接入相应状态数据。没有合法数据时保持空态或替代显示，不凭动画推测运行结果。

## 属性

优先在项目已有 Plugin 应用文件中设置参数；不需要为了改外观复制官方实现。

| 参数 | 用途 |
| --- | --- |
| `rootProps` | 最外层区域的样式和 DOM 属性。 |
| `statusProps` | 定制对应区域的 DOM、样式或交互参数。 |
| `renderStatus` | 替换对应内容的展示，保留当前数据与交互。 |
| `Fallback` | 无法展示合法内容时的替代组件。 |

## 验证结果

在当前项目检查正常、不可用、失败和取消中与此功能相关的状态。涉及附件、语音、登录、历史和恢复时，分别测试实际业务服务；使用 Mock 时注明它是演示数据。

如果只通过类型检查或构建，仍需在页面验证。失败时查看具体提示，不直接清空工程或覆盖已有定制。
