# 显示完整对话区（conversation-surface）

组合实时与历史会话的空态、消息区、输入区及各 renderer。

## 界面与功能

一个完整对话区包含空态、消息、工具结果和输入区；查看历史时只提供后端允许的操作。

## 如何启用和使用

在已创建的工程中启用此 Plugin，放到当前组合支持的位置。可以请 Creator 按下方示例调整；先保留已有页面和其他功能，再检查预览效果。

当前官方预设：在工作台、悬浮式、嵌入式中启用。已有项目可能已经定制，以实际页面为准。

可以把下面的需求发给 Creator：

> 在当前工程中配置「显示完整对话区」，保留已有布局和其他功能。先检查所需服务是否可用，完成后说明改了哪里、怎样验证。

## 使用前提

保留当前会话服务和各项已启用功能。只有 Agent 返回相应内容时才显示工具、计划或结构化结果。

## 属性

优先在项目已有 Plugin 应用文件中设置参数；不需要为了改外观复制官方实现。

| 参数 | 用途 |
| --- | --- |
| `rendererSlots` | 替换对应内容的展示，保留当前数据与交互。 |
| `rootProps` | 最外层区域的样式和 DOM 属性。 |

## 验证结果

在当前项目检查正常、不可用、失败和取消中与此功能相关的状态。涉及附件、语音、登录、历史和恢复时，分别测试实际业务服务；使用 Mock 时注明它是演示数据。

如果只通过类型检查或构建，仍需在页面验证。失败时查看具体提示，不直接清空工程或覆盖已有定制。

> 截图待补：主界面组合与历史。展示用户实际入口和操作结果；服务配置类通过受影响的对话、列表、主题或账号区域展示。
