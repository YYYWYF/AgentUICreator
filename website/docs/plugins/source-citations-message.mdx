# 查看引用来源（source-citations-message）

在回复中列出所引用的网页或文档来源，方便用户查证回答依据。

## 界面与功能

来源会显示为带标题的入口。用户可以打开可访问的网页，或查看文档来源标识，确认回答引用了哪份资料。

![查看引用来源（source-citations-message）界面示例](/images/plugins/source-citations-message.png)

## 如何启用和使用

在已创建的工程中启用此 Plugin，放到当前组合支持的位置。可以请 Creator 按下方示例调整；先保留已有页面和其他功能，再检查预览效果。

当前官方预设：未默认加入三种形态，需要按项目需求启用。已有项目可能已经定制，以实际页面为准。

可以把下面的需求发给 Creator：

> 在当前工程中配置「查看引用来源」，保留已有布局和其他功能。先检查所需服务是否可用，完成后说明改了哪里、怎样验证。

## 使用前提

来源地址和内容由业务服务提供。摘要可能被裁剪，重要结论应打开原文核对。

## 属性

优先在项目已有 Plugin 应用文件中设置参数；不需要为了改外观复制官方实现。

| 参数 | 用途 |
| --- | --- |
| `rootProps` | 最外层区域的样式和 DOM 属性。 |
| `sourceProps` | 定制对应区域的 DOM、样式或交互参数。 |
| `renderSource` | 替换对应内容的展示，保留当前数据与交互。 |
| `renderSources` | 替换对应内容的展示，保留当前数据与交互。 |
| `Fallback` | 无法展示合法内容时的替代组件。 |

下面是复用公开组件的应用层写法，放在现有组件上下文中使用。`props` 来自该组件公开类型，文案由项目语言配置传入：

```tsx
import type { ComponentProps } from "react";
import { CanonicalSourceCitationsMessage } from "@za38.03/agent-ui-plugins";

type Props = ComponentProps<typeof CanonicalSourceCitationsMessage>;
export function ProjectView(props: Props) {
  return <CanonicalSourceCitationsMessage {...props} />;
}
```

## 验证结果

在当前项目检查正常、不可用、失败和取消中与此功能相关的状态。涉及附件、语音、登录、历史和恢复时，分别测试实际业务服务；使用 Mock 时注明它是演示数据。

如果只通过类型检查或构建，仍需在页面验证。失败时查看具体提示，不直接清空工程或覆盖已有定制。
