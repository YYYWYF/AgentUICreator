# 引用来源（source-citations-message）

来源会显示为带标题的入口。用户可以打开可访问的网页，或查看文档来源标识，确认回答引用了哪份资料。

日常调整可以交给 Creator；需要自己写代码时，直接查看[属性](#属性)。

![查看引用来源（source-citations-message）界面示例](/images/plugins/source-citations-message.png)

## 启用与使用

在 **Creator 输入框**输入 `/enable source-citations-message`，点击下图中的 **「查看引用来源」**。

![Creator 启用菜单：点击「查看引用来源」，插件 ID 为 source-citations-message](/images/plugins/enable/source-citations-message.jpg)

## 显示条件与数据来源

**Agent 服务接入：**当前默认注册工具名为 `search_sources`，从工具结果的 `sources` 数组显示来源。以下事件按顺序发送；完整 SSE 包装和运行开始、结束事件见[共用格式](./ag-ui-data#共用的-sse-格式)。

```json
[
  {
    "type": "TOOL_CALL_START",
    "toolCallId": "call-1",
    "toolCallName": "search_sources"
  },
  {
    "type": "TOOL_CALL_ARGS",
    "toolCallId": "call-1",
    "delta": "{\"query\":\"退款政策\"}"
  },
  {
    "type": "TOOL_CALL_END",
    "toolCallId": "call-1"
  },
  {
    "type": "TOOL_CALL_RESULT",
    "messageId": "result-1",
    "toolCallId": "call-1",
    "role": "tool",
    "content": "{\"sources\":[{\"sourceType\":\"url\",\"id\":\"policy-web\",\"url\":\"https://example.com/policy\",\"title\":\"退款政策\"},{\"sourceType\":\"document\",\"id\":\"policy-doc\",\"title\":\"内部政策\",\"mediaType\":\"application/pdf\",\"filename\":\"政策.pdf\"}]}"
  }
]
```

每个来源需要唯一且非空的 `id`。`sourceType: "url"` 需要有效 HTTP(S) `url`，`title` 可省略，提供时不能为空；`sourceType: "document"` 需要非空 `title`、`mediaType`，`filename` 可省略，提供时不能为空。文档来源描述引用资料，不自动提供下载地址。

仅工具已完成、非错误且整个结果有效时展示来源，否则回退工具详情。这里没有 `SOURCE_*` 事件；`sources` 是工具业务结构，也不是附件的 `document.source`。

## 定制选项

| 可以改什么 | 效果 |
| --- | --- |
| 来源之间的间距 | 调整整组来源的布局、边框和间距。 |
| 来源标题 | 修改链接显示的名称，保留原来的地址。 |
| 单个来源 | 自定义每个来源的图标、标题和排版。 |
| 整组来源 | 把整组来源换成自己的列表或卡片。 |

## 属性

打开项目中的 `plugins/source-citations-message/index.tsx`，在已有公开组件调用处设置属性或调整组合。修改外观时，保留文件中读取会话状态、调用服务、显示子插件和注册消息组件的代码。

`?` 表示可选；“省略时”描述当前组件行为。`ReactNode`、`CSSProperties`、`ComponentProps` 等为 React 类型；完整类型以项目实际安装版本为准。

组件：`CanonicalSourceCitationsMessage`；类型：`SourceCitationsMessageProps`。还接受下方列出的工具调用数据、样式和无障碍属性。

| 属性 | 类型 | 省略时 / 用途 |
| --- | --- | --- |
| `sourceProps?` | [`(source: ConversationSourcePart, index: number) => ConversationSourcePart`](#conversationsourcepart) | 转换每个来源对象；需保持 URL／文档来源的联合类型约束 |
| `renderSource?` | [`(source: ConversationSourcePart, index: number, tool: ConversationToolCallProps) => ReactNode`](#conversationsourcepart) | 自定义单个来源，默认 `ConversationSource` |
| `renderSources?` | [`(sources: readonly ConversationSourcePart[], tool: ConversationToolCallProps) => ReactNode`](#conversationsourcepart) | 自定义整个列表，优先于 `renderSource` |
| `Fallback?` | `ComponentType<ConversationToolCallProps>` | 默认 `ConversationToolFallback`；未完成、出错或来源数据无效时使用 |

`sourceProps` 是转换函数，不是任意 HTML 属性对象。

### 外观与无障碍属性

以下属性均可选。

| 属性 | 类型 | 用途 |
| --- | --- | --- |
| `className` | `string` | 整体样式类 |
| `style` | `CSSProperties` | 整体内联样式 |
| `id` | `string` | 元素标识 |
| `role` | `HTMLAttributes<HTMLElement>['role']` | 无障碍角色 |
| `aria-label` | `string` | 无障碍名称 |
| `aria-describedby` | `string` | 描述元素 ID |
| `onClick` | `MouseEventHandler<HTMLElement>` | 点击回调 |

### 当前工具调用的数据与操作

这些数据和方法由现有会话传入，类型为 `ConversationToolCallProps`。`toolCallId`、`toolName`、`args`、`status` 是必需字段，其余已列出的字段可选；修改展示时保留原有传参。

| 属性 | 类型 | 用途 |
| --- | --- | --- |
| `type?` | `'tool-call'` | 消息片段类型 |
| `toolCallId` | `string` | 工具调用 ID |
| `toolName` | `string` | 工具名称 |
| `args` | `unknown` | 解析后的输入参数 |
| `argsText?` | `string` | 输入参数的文本形式 |
| `result?` | `unknown` | 工具结果 |
| `messages?` | `readonly ConversationMessage[]` | 关联的嵌套消息 |
| `isError?` | `boolean` | 结果是否为错误 |
| `status` | [`ConversationToolCallStatus`](#conversationtoolcallstatus) | 工具当前状态：运行中、已完成、未完成或等待用户操作 |
| `addResult?` | `(result: unknown) => void` | 提交前端工具结果 |
| `resumeInterrupt?` | `(payload: unknown) => Promise<void>` | 提交恢复数据，让暂停的任务继续执行 |
| `decisionRequest?` | [`ConversationCommandDecisionRequest`](#conversationcommanddecisionrequest) | 运行环境提供的操作确认请求 |
| `submitDecision?` | `(decisionType: string) => Promise<void>` | 提交后端支持的决定 |

该类型允许传入额外字段，但字段是否生效取决于组件实现，不能据此添加任意配置项。

### 类型说明

#### ConversationSourcePart

一个引用来源，由 `sourceType` 区分网页和文档。

```ts
type ConversationSourcePart =
  | { sourceType: 'url'; id: string; url: string; title?: string }
  | { sourceType: 'document'; id: string; title: string; mediaType: string; filename?: string };
```

`id` 是来源标识；网页来源必需 `url`，标题可选；文档来源必需标题和 MIME 类型 `mediaType`，文件名可选。这是组件的展示类型。

#### ConversationToolCallStatus

按 `type` 区分工具状态：运行中、已完成、未完成和等待用户操作。

```ts
type ConversationToolCallStatus =
  | { type: 'running' }
  | { type: 'complete' }
  | { type: 'incomplete'; reason?: string; error?: unknown }
  | { type: 'requires-action'; reason?: string };
```

`reason` 是可选原因，`error` 是未完成时的可选错误详情。

#### ConversationCommandDecisionRequest

运行环境提供的操作确认请求。

```ts
interface ConversationCommandDecisionRequest {
  allowedDecisions: readonly string[]; // 后端允许提交的决定标识
  description?: string; // 请求说明
}
```

提交决定时使用 `allowedDecisions` 中的原始标识。
