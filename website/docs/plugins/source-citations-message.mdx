# 引用来源（source-citations-message）

来源会显示为带标题的入口。用户可以打开可访问的网页，或查看文档来源标识，确认回答引用了哪份资料。

日常调整可以交给 Creator；需要自己写代码时，直接查看[手动开发](#手动开发)。

![查看引用来源（source-citations-message）界面示例](/images/plugins/source-citations-message.png)

## 启用与使用

在 **Creator 输入框**输入 `/enable source-citations-message`，点击下图中的 **「查看引用来源」**。

![Creator 启用菜单：点击「查看引用来源」，插件 ID 为 source-citations-message](/images/plugins/enable/source-citations-message.jpg)

## 定制选项

| 可以改什么 | 效果 |
| --- | --- |
| 来源之间的间距 | 调整整组来源的布局、边框和间距。 |
| 来源标题 | 修改链接显示的名称，保留原来的地址。 |
| 单个来源 | 自定义每个来源的图标、标题和排版。 |
| 整组来源 | 把整组来源换成自己的列表或卡片。 |

## 需求示例

```text
请修改「查看引用来源（source-citations-message）」：
修改：来源标题字号设为【13px】，每条来源前加【链接图标】，来源间距设为【8px】。
保留：原有来源名称和链接地址。
```

## 手动开发

打开项目中的 `plugins/source-citations-message/index.tsx`，在已有公开组件调用处设置属性或调整组合。修改外观时，保留文件中读取会话状态、调用服务、显示子插件和注册消息组件的代码。

### 属性

`?` 表示可选；“省略时”描述当前组件行为。`ReactNode`、`CSSProperties`、`ComponentProps` 等为 React 类型；完整类型以项目实际安装版本为准。

组件：`CanonicalSourceCitationsMessage`；类型：`SourceCitationsMessageProps`。还接受下方列出的工具调用数据、样式和无障碍属性。

| 属性 | 类型 | 省略时 / 用途 |
| --- | --- | --- |
| `sourceProps?` | `(source: ConversationSourcePart, index: number) => ConversationSourcePart` | 转换每个来源对象；需保持 URL／文档来源的联合类型约束 |
| `renderSource?` | `(source: ConversationSourcePart, index: number, tool: ConversationToolCallProps) => ReactNode` | 自定义单个来源，默认 `ConversationSource` |
| `renderSources?` | `(sources: readonly ConversationSourcePart[], tool: ConversationToolCallProps) => ReactNode` | 自定义整个列表，优先于 `renderSource` |
| `Fallback?` | `ComponentType<ConversationToolCallProps>` | 默认 `ConversationToolFallback`；未完成、出错或来源数据无效时使用 |

`ConversationSourcePart` 为 URL 来源 `{ sourceType: 'url'; id: string; url: string; title?: string }` 或文档来源 `{ sourceType: 'document'; id: string; title: string; mediaType: string; filename?: string }`。`sourceProps` 是转换函数，不是任意 HTML 属性对象。

#### 外观与无障碍属性

以下属性均可选。

| 属性 | 类型 | 用途 |
| --- | --- | --- |
| `className` | `string` | 整体样式类 |
| `style` | `CSSProperties` | 整体内联样式 |
| `id` | `string` | 元素标识 |
| `role` | `HTMLAttributes<HTMLElement>['role']` | 无障碍角色 |
| `aria-label` | `string` | 无障碍名称 |
| `aria-describedby` | `string` | 描述元素 ID |
| `onClick` | `MouseEventHandler<HTMLElement>` | 点击回调 |

#### 当前工具调用的数据与操作

这些数据和方法由现有会话传入，类型为 `ConversationToolCallProps`。`toolCallId`、`toolName`、`args`、`status` 是必需字段，其余已列出的字段可选；修改展示时保留原有传参。

| 属性 | 类型 | 用途 |
| --- | --- | --- |
| `type?` | `'tool-call'` | 消息片段类型 |
| `toolCallId` | `string` | 工具调用 ID |
| `toolName` | `string` | 工具名称 |
| `args` | `unknown` | 解析后的输入参数 |
| `argsText?` | `string` | 输入参数的文本形式 |
| `result?` | `unknown` | 工具结果 |
| `messages?` | `readonly ConversationMessage[]` | 关联的嵌套消息 |
| `isError?` | `boolean` | 结果是否为错误 |
| `status` | `ConversationToolCallStatus` | 工具当前状态：运行中、已完成、未完成或等待用户操作 |
| `addResult?` | `(result: unknown) => void` | 提交前端工具结果 |
| `resumeInterrupt?` | `(payload: unknown) => Promise<void>` | 提交恢复数据，让暂停的任务继续执行 |
| `decisionRequest?` | `ConversationCommandDecisionRequest` | 运行环境提供的操作确认请求 |
| `submitDecision?` | `(decisionType: string) => Promise<void>` | 提交后端支持的决定 |

`ConversationToolCallStatus` 为 `{ type: 'running' }`、`{ type: 'complete' }`、`{ type: 'incomplete'; reason?: string; error?: unknown }` 或 `{ type: 'requires-action'; reason?: string }`。`ConversationCommandDecisionRequest` 含 `allowedDecisions: readonly string[]` 和可选 `description: string`。

该类型允许传入额外字段，但字段是否生效取决于组件实现，不能据此添加任意配置项。

### 类型查询

可在编辑器中通过公开组件取得完整属性类型：

```ts
import type { ComponentProps } from 'react';
import type { CanonicalSourceCitationsMessage } from '@za38.03/agent-ui-plugins';

type ImplementationProps = ComponentProps<typeof CanonicalSourceCitationsMessage>;
```

组件定制方式见[组件定制指南](/development/component-customization)；配置位置和子插件顺序见[布局与插件组合](/development/layout-and-composition)。
