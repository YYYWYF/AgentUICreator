# 语音输入（dictation-action）

控制语音输入开始和停止，把识别结果交给当前草稿。

## 界面与功能

语音按钮开始录入，再次操作停止，识别出的文字进入当前草稿供确认。

![语音输入（dictation-action）界面示例](/images/plugins/dictation-action.png)

截图来源：本项目实际组件的本地 Mock 演示。数据与服务为演示替身。

## 如何启用和使用

在已创建的工程中启用此 Plugin，放到当前组合支持的位置。可以请 Creator 按下方示例调整；先保留已有页面和其他功能，再检查预览效果。

当前官方预设：未默认加入三种形态，需要按项目需求启用。已有项目可能已经定制，以实际页面为准。

可以把下面的需求发给 Creator：

> 在当前工程中配置「语音输入」，保留已有布局和其他功能。先检查所需服务是否可用，完成后说明改了哪里、怎样验证。

## 使用前提

需要麦克风权限、可用设备与已接入转写服务。浏览器权限拒绝与服务失败分别处理。

## 属性

优先在项目已有 Plugin 应用文件中设置参数；不需要为了改外观复制官方实现。

| 参数 | 用途 |
| --- | --- |
| `style` | 局部尺寸或样式。 |
| `disabled` | 按业务条件限制交互。 |
| `className` | 沿用工程样式命名设置外观。 |
| `children` | 替换或补充组件内容。 |
| `onClick` | 自定义点击反馈，保留原有默认动作。 |
| `actionProps` | 定制对应区域的 DOM、样式或交互参数。 |

## 验证结果

在当前项目检查正常、不可用、失败和取消中与此功能相关的状态。涉及附件、语音、登录、历史和恢复时，分别测试实际业务服务；使用 Mock 时注明它是演示数据。

如果只通过类型检查或构建，仍需在页面验证。失败时查看具体提示，不直接清空工程或覆盖已有定制。
