# 依赖包与入口

接入时只安装当前工程需要的包，沿用已有 React、UI 库和构建配置。普通用户从 Creator 的初始化和接入指引开始，不需要手动拼装工具内部模块。

## 常用入口

| 你要做什么 | 使用方式 |
| --- | --- |
| 安装开发助手 | 将 `@za38.03/agent-ui-creator` 作为开发依赖，运行 CLI。 |
| 在业务页面放助理 | 导入项目生成目录的 `Agent`。 |
| 用业务按钮发送或停止 | 使用 `@za38.03/agent-ui-runtime` 的 Host API。 |
| 定制官方组件 | 使用 `@za38.03/agent-ui-plugins` 的公开组件与参数。 |
| 手写布局组件 | 使用 `@za38.03/agent-ui-renderer` 的公开类型和 LayoutRenderer。 |
| 对接状态/输入等类型 | 使用 `@za38.03/agent-ui-core` 的公开合同。 |
| 在 Vue/HTML 中嵌入 | 使用构建好的 Web Component，或其公开 register 入口。 |

## 哪些属于生产依赖

生成的 Agent 使用的运行包与 UI 依赖随项目构建。Creator 属于开发工具，发布后的页面不需要启动它，也不应请求开发 Mock 或工具转发。

## 可选组件

Lexical 输入、Generative UI、附件、语音、反馈和历史按项目需要接入。存在包出口不代表默认全部启用；额外 peers 与业务服务以前置要求为准。见[可选能力](../customization/testing-and-optional-entries)。

## 查看版本

当前版本从项目实际安装、锁文件和更新页面读取，不从教程示例推算。推荐组合以更新中心显示的兼容目标为准，不把所有包都改成 latest。未有真实发行记录时不添加自某版本起支持的说明。
