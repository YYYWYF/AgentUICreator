# 正式发布记录

当前仓库的审核兼容发行历史 `releases/compatibility.json` 中 `releases` 为空，因此这里没有可列出的正式发行记录。仓库 package.json 的版本和测试 fixture 不作为已发布版本证明。

## 如何阅读后续发行

正式记录需要关联真实 npm 精确版本、包产物和兼容组合。相关包独立版本，某个 Plugin 的实现版本不一定等于 Plugins 包版本。

每次记录应区分新增、修复、破坏性变化和迁移要求，注明影响包或 Plugin。更新中心跨版本升级显示整个区间累计变化，历史缺口需要披露。

## 查询当前安装

在实际项目查看 package.json、锁文件及解析身份；通过更新中心读取项目 registry 的真实元数据。未发布组合、部分发布和离线缓存不能显示为已完成发布或已是最新。

已有源码拥有实现还要查看 原始版本和本地修改，不能用 npm 版本推断它已同步。源码更新见[更新中心](./index)。
