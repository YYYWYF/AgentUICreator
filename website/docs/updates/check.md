# 检查更新和阅读变化

Creator 在启动、选择项目和打开更新页时有界检查，也可手动刷新。检查只读，不安装、合并或推进源码基线。

## 阅读检查状态

在线发现默认使用目标工程的 npm registry、scope 配置与凭据。官方兼容清单随包提供，不能仅按 latest 版本猜测组合。

| 结果 | 解释 |
| --- | --- |
| 有兼容目标 | 可以阅读版本和变更，尚未执行升级。 |
| 较新但不兼容 | 查看依赖、peer 或工具前置阻塞。 |
| 组合部分发布 | 缺少准确包产物，不作为可执行组合。 |
| 缓存或离线 | 结果可能过期，不能确认最新。 |
| 元数据不可用 | 检查 registry、认证或网络，不等于无更新。 |

## 累计变化

从当前版本到选定目标阅读整个区间的新增、修复、破坏性变化和迁移要求。需要时展开逐版详情。多补丁跳跃通常形成一份具体计划，不需要逐补丁确认；历史缺口必须显示。

对源码拥有 Plugin，同时查看已安装包、源码基线、本地修改与目标。新包版本不表示本地实现已经同步。

确认目标工程及当前实际解析版本，声明与安装不一致时先处理差异。工具自身的 Plugins 版本不能代替项目安装身份。

> 截图待补：兼容目标、不兼容原因、过期缓存、元数据失败和缺失历史，展示最后检查时间。
