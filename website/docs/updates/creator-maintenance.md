# Creator 更新

## 1.0.0

通过对话搭建和定制 Agent 前端，在业务页面中边看效果边修改。

- **工程初始化与接入**：在现有工程中创建 Agent UI，提供聊天工作台、悬浮助手和嵌入式布局；支持 React 接入，以及通过 Web Component 接入 Vue、HTML 等页面。
- **对话式定制**：检查工程、讨论方案，修改布局、主题、尺寸、文案、组件组合和交互，并运行相关工程检查。
- **插件管理**：通过 `/enable` 添加或启用插件、`/disable` 停用实例、`/sync` 刷新注册表；支持开发自定义插件。主题通过 `Agent` 参数配置。
- **组件深度定制**：调整组件参数、组合和结果渲染；经确认后，可将指定官方插件的源码交给项目维护。
- **业务服务接入**：协助配置 AG-UI 地址、历史会话、附件、语音、反馈和前端工具等连接，按项目需要接入业务服务。
- **模拟联调**：启动内置 Mock 场景，测试流式回复、工具调用、审批、提问、任务进度和异常状态；支持浏览器复制数据的本地回放及播放时长调整。
- **版本维护**：查看插件可用版本和变更，确认方案后升级项目依赖，或同步已接管的插件实现并保留本地定制。
- **开发工具配置**：提供 CLI、模型服务配置、项目选择与中英文界面。生成的 Agent 前端可独立构建和部署。

操作方法见[Creator 使用指南](/guide/)，首次搭建见[开始使用](/start/)。

## 如何更新 Creator

在安装 Creator 的工程中，按以下步骤更新：

1. 结束当前任务，停止 Creator 和页面开发服务。
2. 打开 `package.json`，在 `devDependencies` 中将 `@za38.03/agent-ui-creator` 的版本号改为需要安装的已发布版本。
3. 使用工程现有的包管理器安装依赖并更新锁文件。
4. 按工程原有的启动方式，重新启动 Creator 和页面开发服务。
