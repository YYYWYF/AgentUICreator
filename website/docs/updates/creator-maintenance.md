# Creator 工具更新

先确认 Creator 安装在哪个工程或工具目录。工具可以与目标工程放在不同位置，更新使用实际安装处的包管理方式。

## 更新开发工具

工具区展示版本与支持范围。目前不能承诺在页面中直接替换正在运行的工具。需要人工更新时先结束任务，保留回执和配置，按原安装目录的包管理流程处理，再重启。

正常安装会处理工具自身依赖，不需要手动混装内部组件。重启后确认当前工程和工具版本，旧升级计划失效时重新检查和确认。

## 更新后检查已有工程

更新工具不应覆盖已生成的界面。已有项目先检查应用文件、连接配置和定制内容；需要迁移时让 Creator 提出具体影响，再决定是否实施。不要为了升级清空原工程。

共享 workspace、yarn/bun 和自动升级按页面实际支持范围处理。能看到更新信息不表示当前环境可以自动执行。

## 验证

重启后发送一次只读问题，确认工具连接。目标工程仍通过自己的 dev/test/typecheck/build 使用和发布，生产页面不依赖开发工具。
