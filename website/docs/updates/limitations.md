# 支持范围与限制

本页集中说明平台、更新与能力的支持边界。查看界面可以提供什么体验时，使用[前端能力概览](../agent-ui/)；配置某项能力时，再进入对应接入或定制文章。

| 能力 | 当前边界 |
| --- | --- |
| Creator 自动升级 | 工具信息可展示，安装宿主替换、自动重启等尚未全面实现。 |
| 共享 workspace 更新 | 不承诺跨成员事务和恢复。 |
| yarn/bun 更新执行 | 不属于当前独立 npm/pnpm 执行范围。 |
| 旧源码自动迁移 | 保留定制与所有权，单独评估迁移。 |
| 前端工具 | 只承诺 root-thread 执行；子代理数据可展示，不推导子代理执行。 |
| 认证/附件/语音/反馈 | 需要 Host 服务或适配器。 |
| 历史与运行恢复 | 需要后端数据与 resume 合同。 |
| Generative UI / Lexical | 可选出口与依赖，显式接入，不默认全部启用。 |
| A2UI | 历史/可选实现不能宣传为默认正式支持。 |
| AI 离线文档工具 | Markdown/索引已交付，专门搜索/读取工具仍是后续工作。 |
| Vue/HTML | 通过 React producer 的 Web Component，不生成原生 Vue Plugin。 |
| 源码接管 | 按具体 Plugin 同意，npm 升级不自动接管或合并你的源码。 |

生产前端始终独立于 Creator。一个应用连接一个主 Agent Runtime，嵌套 Agent 展示不扩展成多 Runtime 路由。

遇到不支持环境时保留只读发现或人工规划，不能通过删除保护文件、猜版本或任意安装命令绕过边界。

> 截图待补：实际界面中的受限/可选状态与明确原因，不制作不存在的执行入口。
