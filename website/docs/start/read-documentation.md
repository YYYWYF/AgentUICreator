## 在线与离线阅读

需要让 AI 阅读时，将以下地址交给它：

| 地址 | 内容 |
| --- | --- |
| 文章路径加 `.md`，如 `/start/read-documentation.md` | 单篇 Markdown |
| `/llms.txt` | 文档目录 |
| `/llms-full.txt` | 文档全文 |

离线时，读取 Creator 安装包中的 `dist/documentation/`；`index.json` 列出文件。这些文档对应已安装的发行版本。

## 交给 AI 或知识库

能访问网站的 AI 可以读取单篇 Markdown，再根据 llms 目录定位相关文章。只有本地文件访问能力时，提供离线目录中的实际文件；企业知识库可导入 Markdown 和引用图片，按自己的访问权限使用。

`llms.txt` 是索引，不会赋予外网 AI 访问内网的权限。将内网地址发给无法访问的模型不会自动同步内容。交付静态站时保留 `.md`、`.txt` 的直接访问，不把所有请求重写成 HTML。

当前已交付离线 Markdown 和资源索引，专门给 Creator 使用的文档搜索/读取工具尚未接入，不能把安装包中有文档等同于已有菜单按钮。
