# 阅读网站与 AI 文档

使用侧栏或搜索框查找操作步骤。

需要让 AI 阅读时，将以下地址交给它：

| 地址 | 内容 |
| --- | --- |
| 文章路径加 `.md`，如 `/start/read-documentation.md` | 单篇 Markdown |
| `/llms.txt` | 文档目录 |
| `/llms-full.txt` | 文档全文 |

离线时，读取 Creator 安装包中的 `dist/documentation/`；`index.json` 列出文件。这些文档对应已安装的发行版本。
