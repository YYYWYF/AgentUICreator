# 启动与连接

先按[开始使用](/start/)启动 Creator 和工程自己的前端开发服务，完成助理组件的挂载。Mock 随 Creator 提供，无需另外安装服务或配置模型密钥。

## 1. 启动 Mock 服务

展开页面中的 Creator，在顶部文件夹菜单确认当前工程，然后点击右上角齿轮，打开 **示例与回放**。

![Creator 设置菜单中的示例与回放入口](/images/start/10-creator-mock-menu.png)

点击 **启动服务**，面板会显示服务的运行状态和地址。

## 2. 选择场景

在列表中选择场景，也可通过「搜索 Mock」查找。如果提示缺少展示插件，按提示引入或启用。

![Mock 场景选择示例](/images/guide/mock-scenario-selection.png)

各场景的说明见[内置场景目录](/mock/builtin-scenarios#内置场景目录)。从浏览器复制的事件数据，按[本地回放说明](/mock/local-recordings)加载。

## 3. 连接页面助理

从 Creator 齿轮菜单打开 **连接 Agent**，选择 Mock 来源并保存。

保存后，页面助理会使用 Mock 服务。此设置仅用于开发预览，不会修改应用代码中的 `endpoint`。

## 4. 发送消息并检查效果

在页面助理中发送一条消息，触发所选场景。根据场景说明检查展示和交互效果。

![Mock 对话中展示的思考、工具执行与最终回复](/images/start/07-demo-conversation.png)

## 切换场景与调整播放时长

重新打开「示例与回放」，选择另一个场景，再次发送消息。新选择用于后续请求，不改变正在输出的回复。

「播放时长倍率」调整事件之间的等待时长，范围为 `0` 到 `10`：

| 倍率 | 播放效果 |
| --- | --- |
| `1` | 按场景预设的间隔输出 |
| 大于 `1` | 延长等待，方便观察流式和处理中状态 |
| 大于 `0` 且小于 `1` | 缩短等待，更快看到结果 |
| `0` | 跳过预设等待 |

倍率不改变事件内容和顺序。检查长文本或中间状态时可以先调大，完成后再恢复为 `1`。

## 停止服务与切回业务 Agent

测试结束后，在「示例与回放」中点击 **停止服务**。关闭面板不会停止服务，退出 Creator 时服务会停止。重启后先检查面板状态，再连接并发送消息。

需要测试真实业务时，在「连接 Agent」中切换到业务服务并保存。正式应用的服务地址仍由应用代码中的 `endpoint` 配置，详见[连接 Agent 服务](/development/connect-agent)。

## 没有看到预期回复时

| 现象 | 检查位置 |
| --- | --- |
| 仍然收到业务服务的回复 | 确认「连接 Agent」已选择 Mock 并保存，然后重新发送 |
| 无法连接或请求失败 | 确认 Mock 已启动，查看面板显示的失败原因 |
| 场景有回复，但没有预期卡片 | 阅读场景的插件提示，引入或启用所需插件后重试 |
| 切换场景后当前回复没有改变 | 等待当前回复结束或停止，再发送一条新消息 |
| 本地回放没有出现 | 确认文件位于当前工程的 `.agent-ui/mocks/`，刷新 Creator 并检查[文件格式与限制](/mock/local-recordings) |
