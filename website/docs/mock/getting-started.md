# 启动与连接

先按[开始使用](/start/)启动 Creator 和工程自己的前端开发服务，完成助理组件与 Creator 开发预览的挂载。Mock 随 Creator 提供，回放本身不调用模型。

## 1. 选择页面助理的来源

展开页面中的 Creator，确认当前工程。点击右上角齿轮，打开 **连接 Agent**，点击 **使用示例 Agent**。

页面显示“当前使用：示例 Agent（Mock）”后，助理会使用 Creator 开发预览中的回放连接。已接入开发预览的工作台无需先启动一个额外的 Mock 监听服务。本轮招行工作台的示例采用此方式，已实际完成预置场景与本地工单录制的回放。

![选择示例 Agent 后，连接面板显示当前来源为 Mock。](/images/guide/examples/20261106/mock-preview-connection.jpg)

这项设置仅用于开发预览，不会修改应用代码中的 `endpoint`。

## 2. 选择场景或本地回放

从齿轮菜单打开 **示例与回放**。在列表中选择场景，也可通过“搜索 Mock”查找。如果提示缺少展示插件，按提示引入或启用。

从浏览器复制的事件数据，可以按[本地回放说明](/mock/local-recordings)保存到当前工程的 `.agent-ui/mocks/`，再从“本地 Mock”列表选择。

![示例与回放面板中的本地工单录制文件。](/images/guide/examples/20261106/mock-local-recordings.jpg)

各预置场景的说明见[内置场景目录](/mock/builtin-scenarios#内置场景目录)。

## 3. 发送消息并检查效果

收起 Creator，在页面助理中发送一条消息，触发所选场景。根据场景说明检查展示、点击、取消和继续回复等行为。

![Mock 对话中展示的思考、工具执行与最终回复。](/images/guide/examples/20261106/verify-success.jpg)

## 切换场景与调整播放时长

重新打开“示例与回放”，选择另一个场景，再发送消息。新选择用于后续请求，不改变正在输出的回复。

“播放时长倍率”调整事件之间的等待时长。面板提供立即完成、0.1×、0.5×、1× 和 2× 五种预设：

| 倍率 | 播放效果 |
| --- | --- |
| `1` | 按场景预设的间隔输出 |
| 大于 `1` | 延长等待，方便观察流式和处理中状态 |
| 大于 `0` 且小于 `1` | 缩短等待，更快看到结果 |
| `0` | 跳过预设等待 |

倍率不改变事件内容和顺序。检查长文本或中间状态时可以先调大，完成后再恢复为 `1`。

## 给外部客户端提供独立地址

需要让其他开发客户端直接请求 Mock 时，在“示例与回放”中点击 **启动服务**。面板会显示独立服务的状态和 AG-UI 地址。当前默认监听 `127.0.0.1:47831`；端口已被占用时会启动失败，不会自动换到其他端口。

关闭面板不会停止独立服务。测试结束后可点击 **停止服务**，退出 Creator 时也会停止。独立监听服务与工作台中的临时回放来源分别管理；停止监听不等于切换页面助理的来源。

## 切回业务 Agent

在“连接 Agent”中填写业务服务地址，点击 **使用此地址**；也可以用 **关闭临时连接** 结束开发预览的覆盖。正式应用的服务地址仍由应用代码中的 `endpoint` 配置，详见[连接 Agent 服务](/development/connect-agent)。

## 没有看到预期回复时

| 现象 | 检查位置 |
| --- | --- |
| 仍然收到业务服务的回复 | 确认“连接 Agent”显示当前使用示例 Agent，再重新发送 |
| 工作台内的回放请求失败 | 确认工程已接入 Creator 开发预览，Creator 与前端开发服务均正常运行 |
| 外部客户端无法请求独立地址 | 检查独立 Mock 服务是否启动、面板地址和端口占用情况 |
| 场景有回复，但没有预期卡片 | 阅读场景的插件提示，引入或启用所需插件后重试 |
| 切换场景后当前回复没有改变 | 等待当前回复结束或停止，再发送一条新消息 |
| 本地回放没有出现 | 确认文件位于当前工程的 `.agent-ui/mocks/`，刷新 Creator 并检查[文件格式与限制](/mock/local-recordings) |
