# 初始化失败、工程损坏和修改未生效

## 初始化冲突

核对工程路径、源码位置、已有目录与缺失依赖。初始化碰到已有实现应保留并先盘点，不直接覆盖或换目录制造第二套注册。

依赖缺失按具体计划安装；源码路径和应用元数据不一致时读取诊断详情。初始化已提交但清理未完成，与完全未写入不同，应按恢复提示重新检查。

## 工程需要修复

记录错误码和具体路径，区分配置损坏、Registry 重复 ID、模型校验失败及 开发工具 需要重启。修复最小文件后重新检查，不删除 `.agent-ui` 重置所有权。

## 页面没变化

确认浏览器地址和 dev 进程属于当前工程。检查 import 指向的生成目录、是否加载旧 bundle、热更新错误及模型修改是否被接受。派生注册表需要同步时用 `/sync`，不是源码升级。

Vue/HTML consumer 使用编译资源，必须重建 React producer 并替换正确资源。不要直接编辑生成压缩文件作为长期定制。

## 验证

运行相关类型检查与构建，在当前页面对比修改目标、滚动和交互。核对回执 revision，旧检查通过不能证明现在页面生效。
