# Creator 入口不出现或连接失败

## 没有入口

确认页面是开发模式，已加载正确 Dock 适配器，并在第一次修改配置后重启了业务开发服务。Creator 不会自动注入未配置的任意页面。

核对当前工程与 Creator 选择身份。Vite 可按工具启停显示入口；Rsbuild/Webpack 通常先启动工具再刷新页面。不要用另一个工程仍在运行的旧端口判断当前状态。

## 展开后连接失败

对照终端实际地址与 `creatorUrl`，确认服务未退出，浏览器能访问。显式端口变更需同时更新工具脚本与适配器。HTTPS 页面访问 HTTP 工具可能受浏览器网络策略影响。

Webpack 检查 HTML 是否经过编译资产管线；后端模板和静态文件不在自动注入范围。Node API 启动 dev-server 需使用插件处理后的选项。

## 最小处理

先修配置或重启属于本任务的工具，不重复初始化业务源码。不需要为了入口问题更改 AppUIModel 或接管 Plugin。

## 验证与材料

检查工具停用时普通页面继续运行，启用后正确工程出现入口，生产构建没有注入。仍失败时提供适配器类型、端口、脱敏网络错误和开发配置片段。
