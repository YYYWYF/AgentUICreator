# 更新、构建与部署失败

## 无更新或被阻塞

区分「确认无兼容更新」与「元数据不可用/缓存过期」。检查 registry、凭据、清单、实际包身份及部分发布状态，不自行组合各包 latest。

计划过期时重新读取当前版本和锁文件，重新确认具体计划。共享 workspace、linked/local 声明和 yarn/bun 执行限制不能通过任意 shell 绕开。

## 安装或恢复失败

按回执阶段处理。声明/锁恢复不代表 node_modules 恢复，保留部分完成状态与额外编辑。未知安装进程需要人工核对，见[恢复](../updates/recovery)。

## 类型与构建

核对共享 API、准确 peers、应用层 props、源码拥有引用及样式入口。不因为 npm 升级自动覆盖本地实现或采用新源码基线。修 API 属单独代码变化。

Vue consumer 无变化时重建 producer 并确认发布的文件摘要。模块加载错误先区分 ESM/classic 和子目录 base。生产缺 CSS、弹层异常与 API 404 分别定位。

## 工具依赖泄漏

若生产报告 开发工具/Node 模块解析，检查 dev-only import 分支及业务入口。将工具配置留在 Host，不通过加运行工具来补生产依赖。
