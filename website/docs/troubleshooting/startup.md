# 安装与启动问题

先保留原始错误信息，再区分安装、运行组件、端口和配置问题。不要先清空工程或锁文件。

## 提示缺少运行组件

确认当前操作系统与架构受支持，原安装是否完成，以及包管理器是否跳过可选依赖。内网镜像需要提供 Creator 的完整依赖；只复制主包可能无法运行。

使用原包管理器在原安装目录修复依赖，保留已有锁文件。正常安装无需另装 Python；不要为掩盖缺包而配置不明解释器或下载任意替代文件。

## registry 与网络

记录失败包名、状态码和实际 registry。401/403 检查凭据与 scope 权限，404 检查版本和镜像同步，证书错误使用企业可信证书。日志移除 token，不关闭 TLS 校验。

## 端口占用或打不开

核对终端显示的实际 URL 与页面 creatorUrl。显式端口占用时，正常停止自己启动的旧工具或换可用端口，并同步开发配置。不要按未知 PID 终止其他进程。

Windows 路径含空格时加双引号。改完开发配置重启业务服务，启动失败则先读终端第一条具体错误。

## 验证恢复

工具页能打开并选中正确工程后，发送一次只读问题。页面正常不代表模型配置也正确，模型失败继续看[模型排障](./model-and-run)。
