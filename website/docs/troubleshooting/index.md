# 问题定位入口

本章在已经发生故障时按症状定位原因。首次安装按[快速上手](../start/)，正常使用按 [Creator 开发指南](../guide/)或[应用接入](../integration/)；更新计划和恢复操作见[版本与更新](../updates/)。

| 现象 | 排查文章 |
| --- | --- |
| 安装失败、Python 平台包缺失、端口占用 | [启动](./startup) |
| 页面没有 Creator 入口或无法连接 | [工具连接](./creator-connection) |
| 模型报错、任务停滞、取消后状态不明 | [模型与运行](./model-and-run) |
| 初始化冲突、工程损坏、修改不生效 | [工程与预览](./project-and-preview) |
| 助理不回复、历史加载或恢复失败 | [Agent 与历史](./agent-and-history) |
| 附件、语音、Plugin、输入菜单不可用 | [Plugin 与输入](./plugins-and-input) |
| 更新失败、构建报错、部署资源异常 | [更新与构建](./updates-and-build) |

## 先保存证据

具体日志来源、复现模板和脱敏范围统一见[收集诊断信息](./diagnostics)。修改问题需要对应回执，Agent 问题需要请求和事件证据。

## 再做最小修复

每次只针对已确认原因改动，然后重试同一操作。不要先删除锁文件、`.agent-ui`、源码或整个缓存。处理前确认修复会改变文件、依赖、服务还是仅刷新显示。

没有后端或浏览器时如实记录未验证，不把 Mock 或静态构建的通过扩大成真实业务验收。

> 截图待补：带错误码、当前工程与时间的最小故障证据示例，脱敏处理。
