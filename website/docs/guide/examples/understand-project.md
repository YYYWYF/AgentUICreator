# 了解当前工程

不知道从哪里开始时，可以先让 Creator 查看现有界面，并明确要求只检查、不修改。

## 可以怎样说

> 帮我看看当前界面有哪些组成部分，哪些可以调整，先不要修改文件。请用简短中文说明。

说明自己看到的页面，例如「AI 工作台里的平台式助理」。工作台包含多个助理入口时，要先确认 Creator 选中的工程与目标入口一致。

## 对照实际页面

本组「AI 工作台」保留左侧聊天、右侧会话列表的布局。右侧包含助理名称、新建会话、搜索和历史记录；左侧包含欢迎内容、推荐问题、消息和输入区。

![招行 AI 工作台：左侧聊天，右侧会话列表。](/images/guide/examples/20261106/cmb-platform-right-before.jpg)

可以继续描述名称、头像、文案、颜色、宽度、按钮位置或交互。你不必记住插件名称，也不必先指出源码文件。

## 核对检查范围

只读检查后，确认回执没有文件修改。Creator 的说明应对应你选中的入口；如果它描述的布局不同，直接指出，例如「我说的是右侧带会话列表的 AI 工作台，先不要调整布局」。

「服务工单」的悬浮球和「业务协同」的嵌入式助理使用各自的模板，见[工作台入口对照](/guide/examples/#本组使用的工作台)。

确定目标后，可以继续[修改名称与欢迎内容](/guide/examples/brand-copy)。
