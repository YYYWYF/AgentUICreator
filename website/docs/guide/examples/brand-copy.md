# 修改名称与欢迎内容

从名称、欢迎语和推荐问题开始，把通用助理换成自己的业务入口。以下请求于 2026 年 10 月 27 日实际执行，没有补充代码或文件位置。

## 本次怎么说

> 把助理名字改成「小招」，欢迎语改成「你好，我是小招，有什么可以帮你？」，推荐问题改为「如何查询账户余额？」「转账多久到账？」「如何查询信用卡账单？」。中英文都保留对应文案，其他布局不变。

![本轮实际发送的名称和欢迎内容需求。](/images/guide/examples/20261027/brand-request.png)

## Creator 实际怎样处理

Creator 自行找到中英文文案并修改了两份语言文件，代码检查通过。它说明没有修改布局，同时明确说自己未做浏览器视觉验收。

![Creator 的真实修改总结与检查回执。](/images/guide/examples/20261027/brand-reply.png)

修改前：

修改后，名称和欢迎语符合请求。下图使用本轮保存的修改后版本重新打开，未手工调整任务代码。

![名称修改后的页面，显示小招、新欢迎语和三张业务推荐卡片。](/images/guide/examples/20261027/brand-after.png)

推荐卡片的**可见标题被 Creator 写成了简短名称**，并未逐字显示请求中的问句。问句用于点击后发送：

| 页面标题 | 点击后发送的问题 |
| --- | --- |
| 账户余额查询 | 如何查询账户余额？ |
| 转账到账时间 | 转账多久到账？ |
| 信用卡账单查询 | 如何查询信用卡账单？ |

本轮实际切换英文检查了名称、欢迎语和推荐内容；在后续局部调整后，也逐一点击三张卡片，确认发送的仍是上表中的问题。

如果要求卡片上也完整显示问句，需要继续指出这一点。本轮没有把它当作已经逐字完成的结果。
