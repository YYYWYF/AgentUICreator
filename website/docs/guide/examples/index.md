# 对话定制示例

直接描述想要的效果和要保留的内容，文件位置与实现方式由 Creator 自行检查。本组示例于 2026 年 10 月 27 日在独立工程中重新执行，用户请求没有附带代码、参数或样式指导。

各页“本次怎么说”是实际发送的原文；Creator 回复按真实记录摘录或概括。成功、未完成和只读检查分别说明，不把改写的提问或旧截图当作本轮结果。

| 需求 | 本轮实际结果 |
| --- | --- |
| [了解当前工程](/guide/examples/understand-project) | 完成只读检查，没有修改文件 |
| [修改名称与欢迎内容](/guide/examples/brand-copy) | 名称和欢迎语生效；卡片标题被简写，发送问句保留 |
| [检查修改结果](/guide/examples/verify-results) | 区分 Creator 的静态检查与浏览器中的 Mock 成功、失败和确认检查 |

## 怎样描述需求

说明改哪里、希望变成什么样、哪些结果要保留即可。没有精确尺寸时，也可以描述你看到的问题。需要中英文时，提供目标文案；只想了解现状时，说“先不要修改文件”。

页面没按预期变化，就继续说明看到的结果。你不必先替 Creator 找代码或决定实现方法。

## 在哪里看结果

在 Creator 中查看回复和修改回执，再打开助手检查实际页面。本组页面截图来自本轮生成代码的浏览器运行；名称阶段和布局基线另用保存的对应代码版本重新打开补拍，已在对应页说明。

语言、主题和回复状态通过独立验证入口检查，只选择连接与语言、主题，没有手工修补任务代码。回复场景使用真实运行的[Mock 服务](/mock/)，Creator 本身使用真实模型。真实业务后端和语音识别没有因此完成验收。

本轮在 macOS Chromium 中运行，未做真实 Windows 测试。具体检查和限制以各页记录为准。
