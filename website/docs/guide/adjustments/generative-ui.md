# Agent 驱动的动态界面

想让助手根据业务数据展示表单时，先说明用户能填什么、提交后做什么。以下是 2026 年 10 月 27 日在同一业务测试工程中继续询问的实际记录。

## 本次怎么说

> 我想让助手按业务数据展示一个工单筛选表单，可以填关键词、选状态，再提交查询。数据不对时给提示，打开历史记录时不要自己查询。先看看现在能不能做、需要我提供什么，先不要修改文件。

## Creator 实际怎样回复

Creator 重新检查后说明：表单外观可以开发，但工程没有承接查询的数据入口。它询问查询方式、关键词与状态的含义，以及正常、空结果和失败三种返回样例。

![本轮实际回复，说明没有查询数据入口，列出待补充信息。](/images/guide/examples/20261027/dynamic-reply.png)

## 本轮结果

没有修改文件，没有实现筛选表单，也没有配置或验证 Agent 驱动的动态界面。页面仍是默认助手，不能把“可以开发”当作“已经支持并完成”。

![这组只读检查后的实际页面，没有新增表单。](/images/guide/examples/20261027/business-unchanged.png)

下一步需要提供真实数据样例、可选状态和提交服务说明，再检查所选方案是否能接收这些数据。实施后还要测试无效数据、提交成功或失败、取消，以及打开历史时不重复提交。

需要自己编写代码时，见[开发文档](/development/component-customization)。
