# 增加新的界面功能

说明功能放在哪里、展示什么、用户能做什么，再让 Creator 检查是否具备接入条件。本页记录 2026 年 10 月 27 日的实际请求和追问。

## 本次怎么说

> 在对话区上方增加“当前工单”卡片，显示工单号、标题和状态。数据来自现有工单服务，点“查看详情”打开业务页面里对应的工单。没有选中工单时隐藏，加载失败时能重试。保留现有会话和输入，支持暂时隐藏再恢复，中英文都要有。先检查还需要我提供什么，先不要修改文件。

首轮 Creator 只回复准备核对，没有给出检查结果。

![本轮首轮实际回复，只有准备检查的说明，未交付结论。](/images/guide/examples/20261027/feature-first-reply.png)

于是继续实际追问：

> 你还没有告诉我检查结果。现在能接这个卡片吗？还缺哪些资料？先不要修改文件。

## Creator 随后给出的结果

追问后，Creator 检查工程并说明：没有已接入的工单服务，暂时无法接上数据。它要求提供当前工单的数据来源、选中工单的时机、详情页面地址，以及隐藏后怎样恢复等信息。

![普通追问后，Creator 实际给出的检查结论与待补充资料。](/images/guide/examples/20261027/feature-info-reply.png)

## 本轮没有实现卡片

两轮都没有修改文件，没有新增“当前工单”卡片，也没有完成详情跳转、重试或中英文展示。

![同一独立工程完成只读检查后的实际页面，没有新增当前工单卡片。](/images/guide/examples/20261027/business-unchanged.png)

提供实际服务文档和页面操作说明后，才能继续实施。完成后按[检查修改效果](/guide/examples/verify-results#检查清单)验证，不能把答应检查当成检查已完成。

希望自己实现时，见[创建自定义插件](/development/create-plugin)。
