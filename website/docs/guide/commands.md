# Creator 快捷命令

在 **Creator 输入框**中输入 `/`，选择命令与选项。点击菜单中的具体选项即执行；手动输入完整命令时，点击「发送」。

| 命令 | 功能 | 示例 |
| --- | --- | --- |
| `/enable` | 添加插件或恢复实例，缺少文件或依赖时先确认补齐 | `/enable dictation` |
| `/disable` | 停用已启用的插件实例 | `/disable attachment` |
| `/sync` | 按当前 Plugin 定义更新注册表 | `/sync` |

运行中、等待回答或工程尚不可用时，先处理当前任务，再使用命令。

主题由业务页面通过 `Agent` 的 `theme` 属性传入，不使用 `/theme` 写入项目配置。接入方式见[主题切换](/development/agent-options#主题切换)。

## 启用插件图示

1. 输入 `/`，点击「启用插件」。

![在 Creator 输入框输入斜杠后，选择「启用插件」。](/images/guide/creator-command-menu.jpg)

2. 输入名称或 ID 筛选，点击目标插件。例如 `/enable dictation` 中的「语音输入」。

![搜索 dictation，选择 ID 为 dictation-action 的「语音输入」。](/images/guide/creator-enable-plugin.jpg)

3. 已启用的实例在 `/disable` 中查找。例如「添加附件」可用 `/disable attachment` 找到；只检查状态时，关闭菜单即可。

![「添加附件」在停用菜单中显示英文插件 ID 和绿色「已启用」标签。](/images/guide/creator-disable-attachment.jpg)

菜单按插件分类展示，支持插件 ID、实例 ID、名称和分类搜索。右侧显示英文插件 ID，下方以绿色「已启用」或灰色「已停用」标签说明状态；悬停英文 ID 可查看对应实例 ID。同一插件有多个实例时，分别选择目标实例。

恢复或停用已有实例会保留原位置和定制代码。停用父插件会隐藏内部界面，恢复子插件时还需确认父插件已启用。

刚完成停用就想改回去，在对应修改回执中点击 **「撤销本次修改」**。以后需要重新启用时，再用 `/enable` 选择已停用的实例。

启用时如果缺少项目文件或依赖，Creator 会先列出要补齐的内容，询问是否继续。确认后补齐；取消则不补齐，也不继续启用。已有定制文件会保留，版本冲突需要另行处理。

选择「尚未添加」的插件后，Creator 会检查工程、安排位置并添加；位置不明确或缺少业务服务时会询问。上传、语音识别等功能仍需接入对应服务，完成情况看后续执行结果。

## 对话定制的适用场景

要同时调整布局或定制行为时，直接描述需求，例如：

> 请启用「添加附件」，保留现有布局，检查上传和文件发送链路。缺少服务时说明需要提供什么。

`/enable` 只提供当前安装版本支持的插件。需要新版能力时，使用[更新中心](/updates/)；`/sync` 只更新注册表，源码合并使用[实现同步](/updates/release-notes#已接管源码的插件)。
