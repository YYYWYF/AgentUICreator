# Creator 快捷命令

在 Creator 输入框中输入 `/`，从命令菜单选择操作。它们属于开发工具，与生成助理输入框里的业务斜杠命令分别管理。

| 命令 | 用途 | 典型输入 |
| --- | --- | --- |
| `/theme` | 设置项目主题 | `/theme dark` |
| `/install` | 选择并安装官方目录中的能力 | 输入 `/install` 后选择当前可用资源。 |
| `/sync` | 按当前 Plugin 定义同步派生注册表 | `/sync` |

主题选项使用当前菜单提供的 `light`、`dark`、`violet`。资源 ID 以工程实际安装的官方 catalog 为准；某个 Plugin 存在于 npm 包，不代表它一定作为独立资源出现在安装菜单中。

## 使用方法

1. 打开已初始化的目标工程，等待运行与问题结束。
2. 输入 `/` 并选择命令与参数，核对菜单中的可用、已安装、可重新启用或冲突状态。
3. 提交，阅读执行活动与文件回执。
4. 回到预览检查结果，运行相关工程检查。

已有但停用的能力可能走重新启用路径；存在冲突时先了解冲突文件，不要删除已有实现。Vue 等兼容宿主的安装操作可能返回接入方案，需要按方案继续，并不表示已安装成功。

## `/sync` 的范围

`/sync` 生成或更新 Plugin Registry，使当前项目定义被正确发现。它不升级 npm 包、不合并官方源码、不推进实现源码基线。源码同步请使用[更新中心的实现同步](../updates/source-sync)。

命令执行中、等待问题、工程尚不可用时，菜单或发送操作可能禁用。出现未知命令或未知参数时，使用菜单列出的当前选项，避免猜测历史资源别名。
