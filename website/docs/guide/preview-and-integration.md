# 查看预览与接入指引

Creator 修改项目文件，业务工程的开发服务负责运行页面。两者分别启动、分别停止，关闭工具面板不会替代业务服务的生命周期管理。

## 打开目标页面

使用工程原有的 `dev` 脚本启动预览。确认地址来自正确工程，避免打开另一个仍在运行的示例进程。首次接入 Dock 或改动构建配置后，重启开发服务使配置生效。

初始化后点击「查看接入方法」，按当前产品形态和源码目录导入组件。React 直接使用生成的 `Agent`；Vue/HTML 使用已构建的 Web Component。容器要有明确高度，详情见[接入路线](../integration/)。

## 修改后检查

普通 React 源码修改通常由开发服务更新页面。若没有变化，检查服务错误、导入位置、当前源码目录与是否使用旧构建输出，再决定刷新或重启。不要首先重复初始化。

Web Component consumer 加载的是编译产物。修改 React producer 的应用层后，重新构建桥接产物，并按既有资源路径更新 consumer；仅刷新 Vue 页面不会让旧产物获得新代码。

## 区分连接和验收

预览可打开不等于真实 Agent 可用；Mock 对话通过也不等于业务认证、上传或历史服务已接入。验证时记录工程地址、Agent 来源、场景与目标状态。

生产发布执行工程自己的构建，不依赖 Creator 服务或开发转发。具体步骤见[独立构建与部署](../integration/production-build)。
