# 打开、切换与关闭工程

Creator 将修改写入当前选中的前端工程。首次使用前，先确认顶部文件夹菜单中的工程身份；工具安装目录、配置目录和目标工程可以是不同目录。

## 打开工程

1. 点击 Creator 顶部文件夹图标，再点击打开工程的按钮。
2. 在系统窗口中选择包含 `package.json` 的前端工程目录。也可以展开「通过路径打开」，填写绝对路径，如 `C:\work\my-app`。
3. 等待检查完成，展开「路径与接入信息」，核对工程路径。

使用 CLI 的 `--project .` 可以预选启动时的当前目录，但不会自动初始化或修改业务页面。目录包含空格时，在终端参数两侧加双引号。

## 处理工程状态

| 状态 | 下一步 |
| --- | --- |
| 尚未初始化 | 选择产品形态与源码位置，按[开始使用](../start/)创建 Agent UI。 |
| 已接入 | 查看接入指引，或直接开始对话修改。 |
| 需要修复 | 展开诊断详情，记录错误码；修复具体文件或服务问题后重新检查。 |
| 工具服务不可用 | 先确认 Creator 进程运行及版本一致，再重新检查工程。 |

不要通过删除 `.agent-ui` 或覆盖源码目录来消除状态提示。这些文件记录工程与源码所有权，重建前必须明确要保留的已有定制。

## 切换与关闭

在菜单中选择其他工程，或输入另一个绝对路径。存在待回答问题时先回答或取消该问题；不要用切换工程替代取消任务。切换后再次核对工程名称，原工程的对话不会作为新工程的修改上下文使用。

「关闭当前项目」保留磁盘文件。它不会卸载依赖、删除生成目录或停止业务工程自己的开发服务。回到同一工程时，重新打开目录并检查其状态。

手动改了配置或源码后，可使用重新检查入口更新工程状态。页面显示未变化时，继续按[工程与预览排障](../troubleshooting/project-and-preview)检查。
