# 管理 Creator 会话

Creator 会话保存开发需求和工作上下文；生成助理的用户聊天记录由目标工程与 Agent 服务管理。清空其中一种不会自动清空另一种。

## 继续一个任务

需要延续相同改造时，在原会话中描述剩余问题，附上当前现象。引用原回执比重新描述全部代码更容易保持范围一致。切换话题之前，确认当前任务没有待回答问题或执行中的操作。

## 清空并重新开始

点击输入框旁的「清空会话」，会清除当前 Creator 的显示记录与草稿，并建立新的对话身份。工程文件和已安装依赖保持在磁盘上；新的会话仍需重新检查工程事实。

运行中或等待回答时不能直接清空。先停止运行或处理问题，再核对已保留的修改。清空对话不会撤销这些修改，也不替代恢复操作。

## 浏览器与工程边界

界面通过浏览器本地存储按工程保存对话相关内容。相同浏览器中的后续打开可以恢复显示；换浏览器、无痕窗口、清理站点数据或更换访问来源时，不保证仍能看到这些记录。

显示记录恢复不等于 Python 执行上下文或外部任务一定能够恢复。旧问题过期时重新规划；不要将日志和密钥当作永久、安全的存储内容。

## 记录重要决定

将需要长期维护的配置和实施结论保存到工程文档或版本控制中。回执用于理解本轮操作，工程文件和明确的源码所有权元数据才是后续开发依据。
