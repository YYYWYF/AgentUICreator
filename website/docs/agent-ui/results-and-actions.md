# 引用来源、文件、图表与回复操作

结构化结果需要 Agent 返回约定数据，并启用对应 renderer。前端不会把任意 JSON 自动认作文件、图表或可信来源。

## 来源与检索

来源卡片可显示标题、链接或检索片段。打开前查看来源地址；片段可能经过裁剪，结论仍需结合完整原文。网页搜索、文档检索和上下文检索有各自的数据入口，不应混用。

## 文件和图表

文件卡片提供服务端允许访问的结果地址。地址失效、鉴权失败或跨域受限时，应由业务服务修复；客户端不能凭本机路径创建可共享链接。

图表按 payload 展示系列、维度与标签。数据缺失或格式无效时可能显示 Fallback。图形显示成功不证明计算结果正确，应同时核对数据和单位。

## 回复操作

复制和导出 Markdown 针对一次完整 assistant 响应，包含该响应中的多条消息。底部操作区通常在响应末尾出现一次；不要逐条重复导出按钮。

反馈按钮将评价交给项目的反馈适配器。没有适配器时，项目可能不显示或不支持提交。提交失败不能显示为已经永久保存。

浏览器剪贴板、下载、链接打开和文件访问受浏览器及部署策略影响。遇到失败保留提示，按[Plugin 排障](../troubleshooting/plugins-and-input)核对能力前提。
