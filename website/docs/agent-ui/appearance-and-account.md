# 语言、主题与账号入口

界面外观和账号控件由工程组合决定。项目可以启用主题、语言、Agent 身份和认证相关 Plugin，也可以通过宿主页面提供这些入口。

## 主题与语言

主题服务支持项目提供的预设；官方展示中包含 `violet`、`light`、`dark`。语言服务提供 `zh-CN` 和 `en-US` 及项目覆盖文案。切换语言会影响界面展示，不会翻译用户消息、协议字段或历史业务数据。

语言控件与主题控件都消费共享服务。某个按钮不存在时，应由开发者决定是否加入组合；不要在浏览器里手改 AppUIModel 冒充项目配置。

## Agent 身份与用户资料

Agent 名称、说明、头像是项目的展示配置。宿主传入的用户名称和头像也只用于展示，不能当作登录凭证或数据权限依据。

## 账号与认证门禁

启用 auth-account 和 auth-gate 后，工程可以展示登录状态、账号菜单与受限内容。实际登录、退出、会话刷新、权限检查由宿主认证服务负责。

认证加载中、未登录、登录失败与已登录应分别显示。客户端隐藏内容不能保护服务端数据；退出后能否清除会话及重新认证，由业务系统定义。
