# 前端能力概览

你可以将 Agent 做成支持流式对话、展示执行过程、允许用户参与决策并呈现结构化结果的交互界面。工作台式、悬浮式和嵌入式决定界面放在哪里；启用的 Plugin、宿主提供的服务和 Agent 返回的数据决定具体具备哪些能力。

本章按能力介绍成品界面可以做到什么，并提供相应操作说明。以下能力可按项目需要组合，不代表每个模板默认启用全部功能。

## 对话交互

基础界面支持编辑问题、发送消息和阅读逐步到达的回复。在此基础上，可以扩展输入方式和对话控制。

| 能力 | 界面可以提供的体验 | 使用前提 |
| --- | --- | --- |
| [消息与流式回复](./messages) | 开场建议、逐步更新的文字，以及 Markdown、代码和表格展示。 | Agent 返回相应内容，项目启用对应展示组件。 |
| [附件、语音与快捷输入](./input-features) | 添加附件、语音转写、引用已有消息，以及通过 `@` 和 `/` 选择资源或命令。 | 按需启用输入插件，并接入上传、转写或候选来源等服务；附件还需 Agent 支持处理。 |
| [停止、重试与编辑](./stop-retry-edit) | 停止当前回复、重新生成答案、编辑已发送内容，以及查看可用的对话分支。 | 当前会话和 Agent 服务支持相应操作；只读历史可能不可用。 |

## 执行过程

界面可以在最终答案之外展示 Agent 正在做什么，并在需要时让用户补充信息或确认操作。

| 能力 | 界面可以提供的体验 | 使用前提 |
| --- | --- | --- |
| [思考、工具与任务进度](./reasoning-and-tools) | 等待提示、思考内容、工具调用及结果、任务计划、进度和嵌套子任务。 | Agent 返回相应事件或约定数据，项目启用对应 Plugin。 |
| [提问、表单与审批](./approval-and-questions) | 在对话中回答选择题、填写表单、允许或拒绝操作，并在提交后继续执行。 | 配置相应交互组件与处理能力，Agent 支持等待、接收结果和继续运行。 |
| [页面业务交互](../integration/frontend-tools) | 由 Agent 请求打开业务弹窗、填写页面表单等已接入的前端动作。 | 宿主明确提供并允许执行这些动作；单独展示工具卡片不会触发业务操作。 |
| [运行状态与恢复](./run-lifecycle) | 区分运行、等待输入、完成、失败和取消；按项目能力提供消息排队与刷新后恢复。 | 队列需项目支持；恢复需后端保留运行信息并提供恢复能力。 |

思考和计划仅展示服务实际返回的内容；工具卡片中的状态也来自实际执行信息。前端不会自行推测步骤或把尚未完成的任务标成成功。

## 结果与体验

回复可以同时包含可阅读、可操作的结果；会话与外观能力则让它融入你的业务应用。

| 能力 | 界面可以提供的体验 | 使用前提 |
| --- | --- | --- |
| [来源、文件与图表](./results-and-actions) | 来源链接、检索片段、生成文件和图表，以及回复复制、Markdown 导出和反馈。 | Agent 返回约定的数据并启用相应展示组件；文件访问与反馈保存需对应服务。 |
| [会话与历史记录](./history) | 新建、查找、切换和读取历史会话；支持时继续旧对话。 | 接入会话服务，历史数据包含所需内容与继续对话的状态。 |
| [主题、语言与账号](./appearance-and-account) | 自定义主题、切换界面语言、设置 Agent 名称与头像、展示账号和登录状态。 | 项目提供相应配置与控件；实际登录和权限校验由业务认证服务负责。 |

布局和样式可通过 Creator 调整，也可以在项目的布局与 Plugin 应用层代码中定制。需要选择具体能力时，查看[Plugin 总览](../plugins/)；开发操作见[界面开发](../guide/)。

## AG-UI 如何支撑这些能力

前端通过 **AG-UI 协议**连接 Agent 服务，接收消息、工具调用、状态和运行生命周期等事件，再将这些更新呈现为界面。图表、业务卡片等内容还需要双方约定数据格式并配置相应组件；接通 AG-UI 并不意味着全部界面能力都会自动出现。

评估效果时，可以先用[模拟联调](../guide/mock/)查看预设响应下的展示与交互，再接入真实 Agent 验证业务流程。Mock 展示成功不能代替对认证、上传、持久历史或恢复能力的实际验收。技术接入见[连接真实 Agent](../integration/connect-agent)。
