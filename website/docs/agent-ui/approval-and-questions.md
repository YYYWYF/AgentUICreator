# 回答问题与处理审批

当 Agent 需要更多信息或请求执行需审批的操作时，对话区会显示问题、表单或审批卡片。先阅读具体操作和影响，再作决定。

## 回答问题

根据卡片选择选项或填写内容，检查必填项后提交。提交会将答案关联到对应中断或工具调用；普通聊天消息不一定能代替卡片答案。

提交后等待卡片和运行状态更新。重复点击可能被界面阻止；若失败，先确认答案是否已被接收，再重试。

## 允许、拒绝与取消

允许表示同意卡片中的具体操作；拒绝是明确不同意；取消或转向表示中止当前交互。服务端可能对三种结果采取不同分支，不能把它们都当作空答案。

审批界面不能替代业务权限校验。账号无权限时，即使客户端选择允许，服务端仍应拒绝越权操作。不要在问题卡片中填写模型密钥或无关敏感凭据。

## 重新进入旧会话

旧审批是否仍有效取决于服务端中断身份、运行状态与恢复能力。过期卡片需要重新请求或重新规划；不得用修改前端状态强制标记审批成功。
