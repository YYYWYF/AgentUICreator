# 附件、语音、引用与快捷输入

输入功能由项目选择的 Plugin 和宿主适配器提供。没有对应服务时，按钮可能隐藏或禁用；出现按钮也不表示上传、识别或人员搜索后端已经配置。

## 附件

点击添加附件，选择文件，等待草稿附件准备完成再发送。检查文件名、状态和可移除入口。失败时按提示重新选择或联系开发者确认类型、大小和上传策略；不要把本机路径当成其他用户可访问的下载地址。

## 语音

使用语音按钮前允许浏览器麦克风权限。再次点击停止，确认转写文本后发送。权限拒绝、设备不可用和服务失败是不同问题；语音 Plugin 本身不提供转写后端。

## 引用

有引用入口时，选取消息内容并加入输入区的引用预览。发送前可检查或移除。引用需要按当前会话语义保存来源；它与网页来源引用卡片不是同一个功能。

## `@` 和 `/`

输入 `@` 搜索宿主提供的人或资源；输入 `/` 使用应用自己的命令。选择项可能插入给 Agent 的结构化指令，也可能执行前端动作，具体取决于项目定义。显示名称可以翻译，内部稳定 ID 不应改变。

菜单无结果时检查搜索词及来源服务，不要认为所有目录和账号都可被搜索。这些业务命令与 Creator 的 `/theme`、`/install`、`/sync` 无关。
