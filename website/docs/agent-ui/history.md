# 新建、查找与切换会话

会话列表来自项目接入的会话服务。没有历史后端时，新建对话仍可能可用，但不能假定刷新后能找回已发送内容。

## 使用列表

打开会话侧栏，使用项目提供的搜索或筛选找到记录，再点击加载。加载过程中等待结果；出现失败提示时使用重试入口，避免将空列表误认为所有会话都已删除。

新建会话会创建新的会话身份。它不会删除其他记录，也不会让后端自动忘记以前的数据。不同账号能看到哪些记录由服务端权限决定。

## 只读与可继续会话

历史数据可能只能用于阅读，也可能包含继续对话所需的完整状态。是否可继续发送、恢复未完成运行或回答旧审批，取决于后端契约和加载结果。

如果界面显示只读，不要通过手动替换线程 ID 绕过限制。联系开发者检查历史消息、工具结果、状态和恢复能力是否完整。

## 删除和切换

有删除入口时，先核对要删除的会话及确认提示。服务端删除失败应保留错误提示，不能把列表暂时消失当作持久删除成功。

运行中切换会话的具体行为由项目线程绑定管理；切换选择与底层运行所有权分别处理，不应把另一个线程的输出显示到当前记录。
