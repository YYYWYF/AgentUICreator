# 发送消息与阅读回复

在助理底部输入框中写入问题，使用发送按钮提交。键盘行为沿用项目当前输入组件的设置；输入法正在组合文字时，应先完成选词，避免把未完成输入发送出去。

## 阅读流式回复

Agent 回复可能逐字或分段到达，也可能先显示思考和工具，再输出文字。一次完整回复可以包含多条 assistant 消息；复制、导出等响应级操作针对这次响应的整体内容。

Markdown 的标题、列表、代码和表格由界面渲染。代码块只是内容，查看代码不会自动执行。来源链接、文件与图表需要相应数据和 Plugin，纯文本回复不会自行生成这些卡片。

## 发送前后状态

输入为空、当前会话禁用、必要服务未就绪或当前运行不允许发送时，发送按钮可能不可用。不要通过反复点击制造重复请求；等待状态变化或查看具体提示。

有消息队列的工程可能把运行期间的输入排到后续执行；未启用队列的工程通常需要先等待或停止。以界面实际显示的排队条目为准。

请求失败时保留错误和已有内容，确认网络与服务状态后再重试。已显示部分文本不表示整个运行成功；同样，网络请求结束也可能代表取消或等待用户操作。

> 截图待补：空输入、流式回复、代码/表格和失败后的部分回复，保留发送与停止按钮状态。
