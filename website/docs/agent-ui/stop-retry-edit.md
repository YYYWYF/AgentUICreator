# 停止、重新生成与编辑消息

这些操作依赖项目提供的输入、消息操作和 Runtime 能力。若当前界面没有相应入口，需要由项目开发者启用，不能仅凭文档假定默认存在。

## 停止当前运行

运行时点击发送区域的停止按钮，等待界面退出运行状态。停止可能保留已经收到的回复，不能撤销 Agent 在服务端已完成的业务操作。重要业务操作应以业务系统记录为准。

## 重新生成回复

在完整响应底部找到重新生成按钮。它会通过现有会话 Runtime 请求新的响应，可能产生新的分支。运行中或只读历史里是否可用，取决于当前会话能力和项目组合。

重试之前确认后端是否会重复执行有副作用的业务动作。前端按钮提供请求入口，幂等与业务授权仍由服务端负责。

## 编辑用户消息

有编辑入口时，打开用户消息的编辑器，调整文本后提交或取消。编辑历史消息可能从该位置形成分支；分支切换应使用界面提供的导航，不能把多个结果拼成一份历史事实。

启用了 Lexical 的工程会保留已识别的提及/指令结构；未启用时使用项目现有文本输入。编辑器不应将协议稳定 ID 翻译成展示标签。
