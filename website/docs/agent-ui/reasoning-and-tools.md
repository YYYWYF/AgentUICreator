# 阅读思考、工具与任务进度

Agent 可以返回推理、工具调用、状态、计划和嵌套任务。前端按收到的数据与启用的 Plugin 展示，不会为了填满界面自行生成执行步骤。

## 等待与思考

等待提示表示回复尚在准备；推理区展示服务实际返回的思考内容。展开或折叠只改变显示，不能停止推理，也不等于停用该能力。只有项目允许显示的内容才应送到客户端。

## 工具执行

工具组按相关调用组织信息，时间线显示调用状态，详情可以包含参数、结果和错误。工具报错后 Agent 可能继续，也可能结束运行，需结合最终状态判断。

工具卡片是展示与交互入口，不是工具后端。未知工具可能由通用 Fallback 展示。审批中的调用应先等待用户决定，不要把「收到调用」视为执行成功。

## 状态、计划与进度

状态卡片描述当前阶段；计划显示后端发布的权威步骤；进度显示任务实际报告的完成度。前端不能因为流结束而自动把所有计划步骤改成完成。

嵌套任务可展开查看子任务信息。子任务的数据缺失、失败或取消应如实显示，不从父任务的结束推断所有子任务成功。

> 截图待补：等待到推理再到工具的连续状态，以及部分失败的计划和嵌套任务；展示状态如何随着真实事件变化。
