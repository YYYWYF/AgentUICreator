# 开发文档

**需要自己编写业务联动、自定义组件或插件时，从这里开始。**你可以直接修改生成工程，也可以与 Creator 配合开发；应用的运行和部署不需要启动 Creator。

本组按[要完成的开发任务](#开发任务索引)组织入口：接入应用、数据与服务接入、插件扩展、界面定制、应用控制与联动、API 与字段参考。了解某个官方插件的功能、数据格式和属性时，进入[插件文档](/plugins/)。

如果只是调整文案、主题、布局或启停功能，先到[使用 Creator](/guide/)描述需求即可，无需先阅读本章。复杂需求同样可以交给 Creator 分析和实现。

## 第一次手动开发

1. 先按[开始使用](/start/)初始化工程，再按 [React](./react)、[Vue](./vue) 或 [HTML](./web-component) 挂载。看到输入框、按钮和样式后，再接业务接口。
2. 按[连接 AG-UI 服务](./connect-agent)完成一次发送、流式回复和停止；还没有后端时，先用 [Mock](/mock/)验证界面。
3. 按需接入历史、上传等[业务服务](./service-integration)，或从[手动修改插件](./component-customization)开始定制。各篇是可选任务，不需要全部实现。

教程默认 Agent UI 源码在 `src/agent-ui/`，业务挂载页为 `src/AssistantPage.tsx`。初始化选择其他目录时，替换对应路径。标为“局部片段”的代码只合入现有文件；标为“完整文件”的代码才适合在无定制的新工程中直接替换。

## 常用名称

| 名称 | 在页面中指什么 |
| --- | --- |
| 助手（Agent） | 一个可独立对话的助手；多个助手用不同 `agentId` 区分。 |
| 会话（Thread） | 一段聊天记录，用 `threadId` 标识；切换工作流或收起面板仍可使用原会话。 |
| 运行（Run） | 一次请求及其输出；同一会话可以先后进行多次运行。 |
| 插件（Plugin） | 输入框、操作按钮、消息卡片或前端服务。启用插件不等于后端已提供相应数据。 |
| 外壳（Shell） | 助手最外层的容器，负责悬浮入口、尺寸和展开收起。 |
